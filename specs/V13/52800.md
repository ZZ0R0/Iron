# [52800]w — io-écriture (puits `Write`, out-direction) — complète l'io de V12

- Version : V13 · Milestone : M13 · Statut : **cadrage** · Dépend de : [52800] (lecture, V12) · Invariants : I2, I6, I10
- V12 a fait la **lecture** (`Read` → `Cursor`, sentinelle `@read`, fns libres/ctors). V13 fait l'**écriture**.

## Objectif
Permettre une fn/méthode externe prenant un **puits `W: Write`** : sauver vers un **fichier** (printpdf
`doc.save(w)`) ou **collecter** une sortie en octets (flate2 compresse → `Vec<u8>`). C'est l'**out-direction**,
plus dure que la lecture (le puits doit être créé, et parfois **récupéré**).

## Périmètre — deux saveurs
- **Vers fichier** (printpdf) : matérialiser `w` depuis un **chemin** Iron → `std::io::BufWriter::new(
  std::fs::File::create(path)?)`. Le retour de la fn (souvent `Result[()]`) est conservé.
- **Vers buffer, rendu** (flate2) : le puits est un `Vec<u8>` ; on écrit ; on **récupère** le `Vec` comme
  `list[u8]`. Pattern multi-statement (créer → écrire/finish → rendre le buffer).

## Décision d'ABI
- Sentinelle **`@write`** (parallèle à `@read`, V12), produite par `bound_to_iron` pour une borne `Write`/`BufWrite`.
- **Position fn libre/ctor** (chemin complet) : **chemin-closure** (comme `@read`) :
  - fichier : `(|__w_path, …args| ORIG(std::io::BufWriter::new(std::fs::File::create(__w_path).unwrap()), …))` ;
    param Iron `str` (le chemin).
  - buffer rendu : `(|…| { let mut __b = Vec::new(); ORIG(&mut __b, …)…; __b })` — variante qui **rend** le buffer
    (type retour Iron `list[u8]`). Choisie quand la fn « écrit puis on veut les octets ».
- **Position méthode** (`doc.save(w)`) : matérialisation **au site d'appel** dans `lower::try_extern_method`
  (le récepteur est `self` ; on ne peut pas closure-wrapper) → l'arg `@write` devient
  `&mut std::io::BufWriter::new(std::fs::File::create(path).unwrap())`.
- Sûr : I2 intact (aucun `unsafe`), I10 (TokenStream).

## Hors-périmètre
- Flux **continu** (écrire au fil de l'eau, gros volumes, `flush` répétés) — on couvre fichier + buffer one-shot.
- `W` générique combiné à d'autres génériques non triviaux dans la même fn.

## Questions ouvertes
- ❓ Choisir « fichier » vs « buffer rendu » : par le **type de retour** de la fn d'origine ? (`-> ()` + écrit →
  fichier/buffer ; heuristique à figer) ou par un suffixe de binding.
- ❓ Méthode avec puits **buffer** (rare) — matérialisation au site d'appel + récupération : à prototyper.
