# [40400] Macros derive émises sur un type Iron

- Version : V12 · Statut : draft (cadrage) · Dépend de : [24100] · Invariants : I6, I10

## Objectif
Émettre des **`#[derive(...)]`** sur les struct/enum Iron quand un crate l'exige : `#[derive(Parser)]`
(pest, clap-derive), `#[derive(Serialize, Deserialize)]` (serde, cf. [52900]). Iron ne génère aucun attribut
derive aujourd'hui.

## Périmètre
- Annoter un type Iron pour qu'il **dérive** un trait via macro (le proc-macro du crate fait le reste).
- Câbler la dépendance Cargo de la macro (`pest_derive`, `serde` features).

## Hors-périmètre
- Écrire des macros derive en Iron ; attributs derive avancés.

## Questions ouvertes
- ❓ Syntaxe Iron pour `@derive(Parser)` / annotation de classe ?
- ❓ pest exige aussi `#[grammar = "..."]` (attribut à valeur) — au-delà du simple derive.

## Done (cible)
Une struct Iron `#[derive(Deserialize)]` désérialise du JSON typé (avec [52900]).
