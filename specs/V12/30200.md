# [30200] Retour emprunté lié à l'entrée (durées de vie `<'a>`)

- Version : V12 · Milestone : M12 · Statut : draft (cadrage) · Dépend de : [30100] · Invariants : I2, I4, I6

## Objectif
Supporter les API **zéro-copie** dont la valeur de retour **emprunte** son entrée :
`Smf::parse(&buf) -> Smf<'a>` (midly), `BitMapBackend::new(&path) -> BitMapBackend<'a>` (plotters). Iron est
par valeur : il crée un **temporaire** pour l'entrée, qui est libéré → `error[E0716]: temporary dropped
while borrowed`.

## Périmètre
- Suivre qu'une valeur **emprunte** une entrée (lifetime `'a` au retour) → garder l'entrée **vivante** aussi
  longtemps que le retour (hisser l'entrée dans un `let` de portée suffisante).

## Hors-périmètre
- Lifetimes multiples/imbriquées arbitraires — viser le cas « le retour emprunte **un** argument ».

## Questions ouvertes
- ❓ Détecter le lien d'emprunt depuis la signature rustdoc (`'a` partagé entrée↔retour) au binding ?
- ❓ Hisser l'entrée : `let __keep = input; let v = parse(&__keep); …` — portée à calculer.
