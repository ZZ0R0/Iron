# [52900] Interop serde **typé** (derive + de/serialize générique)

- Version : V12 · Milestone : M12 · Statut : draft (cadrage) · Dépend de : [24100] · Invariants : I6, I10

## Objectif
Sérialiser/désérialiser vers des **types Iron** : `from_str::<MaStruct>(s)`, `to_string(&maStruct)`. Bloque
le **document** TOML, serde_yaml, bincode, jsonwebtoken (claims). La voie **dynamique** marche déjà
(`serde_json::Value` ✅, `toml::Value` partiel) — c'est la voie **typée** qui manque.

## Périmètre
- Émettre `#[derive(Serialize, Deserialize)]` sur les **struct/enum Iron** marqués sérialisables.
- Câbler `from_str::<T>`/`to_string` avec `T` = un type Iron (exige le suivi de génériques de type, [24100]).

## Hors-périmètre
- Attributs serde avancés (`#[serde(rename, flatten…)]`) en V12.

## Questions ouvertes
- ❓ Toutes les structs Iron dérivent serde par défaut, ou sur annotation ?
- ❓ Forte dépendance à [24100] (passer `T` concret à `from_str::<T>`).
