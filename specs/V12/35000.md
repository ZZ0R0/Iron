# [35000] Boucle d'événements & état mutable partagé

- Version : V12
- Milestone : M12
- Statut : draft (cadrage)
- Dépend de : [30100] résolveur clone/move, [50900] types externes
- Invariants applicables : I2 (jamais d'`unsafe`), I4 (clone-fallback explicite), I6, I10

## Objectif

Permettre les programmes **pilotés par événements** avec un **état mutable persistant** entre les itérations :
GUI (egui/iced/eframe), TUI complets (ratatui), jeux (macroquad/bracket-lib). Aujourd'hui un **mur
structurant** : Iron est **par valeur, sans état global mutable** ; or ces crates tournent sur
`loop { redraw(&mut state); handle_input(&mut state) }` — un état muté à chaque frame, partagé entre la
boucle et les handlers.

## Périmètre

- Un **modèle d'état mutable de boucle** : une valeur (struct Iron) que la boucle d'événements **mute en
  place** d'un tour à l'autre, sans la cloner ni violer la sémantique par valeur ailleurs.
- L'interop avec une **boucle pilotée par le crate** (eframe `run_native`, macroquad `next_frame().await`,
  ratatui `terminal.draw(|f| …)`) : Iron fournit un **callback** qui reçoit `&mut state` (+ le contexte de
  rendu) et le crate l'appelle.

## Hors-périmètre

- État **global** mutable arbitraire (rester sur un état **explicitement passé** à la boucle).
- Async (→ [53000]) — bien que certaines boucles de jeu soient `async`.

## Comportement attendu (esquisse)

```
# Iron (forme cible — à arrêter en planif)
class Counter:
    n: int

def main():
    run_gui(Counter(n=0), draw)      # le crate pilote la boucle, rappelle `draw(&mut state, ui)`

def draw(state, ui):                  # state : &mut Counter ; muté en place
    if ui.button("clic"):
        state.n = state.n + 1
    ui.label(str(state.n))
```

## Questions ouvertes (cadrage)

- ❓ Callback `&mut state` : comment le concilier avec la résolution clone/move (I4) sans `unsafe` ?
- ❓ Le contexte de rendu (`ui`/`frame`) est un **emprunt** fourni par le crate → lié à [30200] (durées de vie).
- 🔶 Faut-il un **type d'état de boucle** dédié, ou réutiliser `shared[T]` (Rc/RefCell, déjà dans l'IR) ?
- 🔶 Frontière avec [53000] : macroquad/bracket-lib bouclent en `async`.

## Critères d'acceptation (cible)

- Une appli egui minimale (un bouton + un label compteur) compile et tourne.
- L'état persiste entre frames sans clone visible (`--audit` propre).
- gate-v11 VERT.

> touche le **modèle d'exécution**, pas le binder. À planifier seule, après [24100].
