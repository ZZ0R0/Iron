# [44000] FONDATION V12 — La couche d'**émission** Rust (RACINE 2)

- Version : V12 · Milestone : M12 · Statut : **cadrage (fondation)** · Dépend de : [24000] · Invariants : I2, I9, I10
- **Rôle** : 2ᵉ des 3 causes racines. Unifie « émettre un item/attribut Rust qu'Iron ne produit pas encore ».

## La cause racine

Plusieurs classes bloquées ne tiennent qu'à **un item/attribut Rust qu'Iron n'émet pas** sur un type/programme
Iron. Iron a **déjà** le pass-through d'attributs (`@derive(...)`, `item_attrs` dans l'IR) — il faut en faire un
**mécanisme d'émission** propre, piloté par les bindings :

| À émettre sur un type/programme Iron | Source de la signature | Débloque |
|---|---|---|
| `#[derive(Serialize)]`/`#[derive(Deserialize)]`/`#[derive(Parser)]` | le `.iri` déclare le trait dérivable | [40400] derive → **serde typé [52900]**, pest, clap-derive |
| `impl ExternTrait for IronType { fn … }` | signatures du trait externe (bindings/rustdoc) | [24300] impl-trait-externe → GUI à trait (eframe/iced), plotters |
| `#![no_std]` + `extern crate alloc` + crate-HAL bénie | mode d'émission + une dep HAL | [43000] embarqué (esp-hal, rppal, linux-embedded-hal) |

→ **Une couche d'émission**, trois usages. Comme pour la racine 1, ajouter un cas = **une entrée**, pas une
réécriture.

## Correction d'une erreur de cadrage (importante)

J'avais classé **[43000] no_std « en tension avec I2 »** et **[24300]/[35000] « incompatibles »**. **Faux** :
- **no_std** : l'`unsafe` vit **dans la crate HAL** (déjà compilée), Iron émet seulement `#![no_std]` + des
  **appels** au HAL. **Iron continue d'émettre 0 `unsafe` (I2 intact).** C'est un **mode d'émission**, pas une violation.
- **impl-trait-externe** : émettre `impl App for MyApp { fn update(&mut self, …) }` est de l'**émission guidée
  par la signature du trait** (connue via bindings). Iron *parse* déjà `impl T for Ty` ; il faut **corriger
  l'émission** (chemins/signatures), pas inventer un concept.

## Périmètre
- **Étendre l'émission** (lowering + IR `item_attrs`) pour : derives nommés, blocs `impl ExternTrait for T`

- Le `.iri` déclare ce qui est **dérivable**/**implémentable** (le trait externe + ses méthodes — déjà presque
  là via `etypes`).
