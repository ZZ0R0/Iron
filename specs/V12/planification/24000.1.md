# 24000.1 — VAGUE 1 (squelette) : le contrat gelé du pont

> **Fondation séquentielle.** Pose le **schéma** partagé et le câble en **pass-through vert**. Rien d'autre
> ne démarre tant que cette unité n'est pas verte : elle **fige les interfaces** que les pistes 2.A/2.B/2.C
> remplissent sans collision.

## Dépendances amont
Aucune (c'est la racine de la V12).

## Périmètre exact (ce qu'on fige, sans encore « remplir »)

1. **Nouveau module `src/bridge.rs`** — squelette des 3 faces + des tables, avec signatures **définitives** :
   - `pub fn project(rd: &Json, cx: &ProjCx) -> Option<Type>` — façade projection (déléguera depuis `bind.rs`).
   - `pub fn coerce_arg(expr: TokenStream, from: &Type, target: &RustParam) -> TokenStream` — façade coercition.
   - `pub fn cast_numeric(expr: TokenStream, from: &Type, to: &Type) -> TokenStream` — **le** point numérique unique.
   - `pub fn rust_num_name(k: NumKind) -> &'static str` — table canonique (déplace `num_kind_str`).
   - Tables **données** (constantes/`static`) : `CONTAINERS`, `BOUND_TO_IRON`, `BYTES`, exposées en lecture.
   - En vague 1 : ces fns **délèguent au comportement actuel** (réexportent `map_type`/`extern_arg_to`/
     `num_kind_str` existants) → **zéro changement de sortie**. Le but est de **publier l'interface**.

2. **ABI génériques externes — `Type::ExternApp(String, Vec<Type>)`** (`ir.rs`, changement de fondation
   **assumé**, additif) :
   - Ajouter la variante. `String` = chemin Rust (comme `Extern`), `Vec<Type>` = args (vide ⇒ opaque).
   - **Lowering** (`lower.rs::lower_type`) : `ExternApp(path, [])` → `path` ; `ExternApp(path, args)` →
     `path::<args>` (réutilise `TokenStream::from_str(path)` + la logique d'args d'`App`, l.2455-2459).
   - **Aucune** autre passe ne produit encore `ExternApp` en vague 1 (binder inchangé) → inerte mais présent.

3. **Schéma `.iri` étendu** (`iri.rs` + `bind.rs` émission) — **figer la syntaxe**, parser tolérant :
   - `extern type Name[T, U] = "path":` → `ExternType.params: Vec<String>` (nouveau champ, `ir.rs`).
   - Type générique externe en signature : `Name[arg, …]` → `Type::ExternApp` au chargement (`iri.rs`).
   - Le parser accepte `Name[...]` pour un nom **externe connu** ; un `.iri` **sans** params reste valide (rétro-compat : `params` vide).

4. **`ExternType.params`** (`ir.rs`) : `pub params: Vec<String>` (défaut `vec![]`), peuplé plus tard (piste 2.A),
   lu plus tard (piste 2.C). En vague 1 : champ ajouté, **vide partout**.

## Fichiers possédés (cette unité, séquentielle — pas de collision possible)
- **Création** : `src/bridge.rs`.
- **Édition** : `src/ir.rs` (variante `ExternApp` + champ `params` + `mod bridge`), `src/lower.rs`
  (`lower_type` : bras `ExternApp` uniquement), `src/iri.rs` (parse `Name[args]` + `[T]` de l'en-tête),
  `src/bind.rs` (émettre `[T]`/`Name[args]` **seulement si params** — sinon inchangé).

## Interface produite (gelée — consommée par 2.A/2.B/2.C)
- Les **signatures** de `bridge::{project, coerce_arg, cast_numeric, rust_num_name}` et la forme des tables.
- `Type::ExternApp(path, args)` + son lowering.
- Schéma `.iri` : `extern type Name[params] = "path":` et `Name[args]` en position de type.
- `ExternType { …, params }`.
