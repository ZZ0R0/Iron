# 24000.3 — VAGUE 2 piste B (`lower.rs`) : numérique unifié + monomorphisation

> Fan-out parallèle (avec 2.A, 2.C). **Ownership : `lower.rs`** (coercition + `lower_type`). Ne touche ni
> `bind.rs` ni `infer/`. Contrat amont gelé par `24000.1`.

## Dépendances amont
`24000.1` vert (`bridge::{coerce_arg, cast_numeric, rust_num_name}`, `Type::ExternApp` + son lowering).

## Périmètre exact

1. **Unifier le numérique (R1)** — supprimer la dette éparpillée. Les trois sites suivants délèguent à
   `bridge::cast_numeric(expr, from, to)` (un seul endroit qui sait « caster `expr` de `from` vers `to` ») :
   - `coerce_to` (l.1967-1977) — coercition de champ/valeur sans `&`.
   - volet **numérique** d'`extern_arg_to` (l.1920-1963).
   - `coerce_sized_binop` (l.2523-2535) — littéral `i64` vers l'opérande dimensionné.
   `num_kind_str` (l.2503-2518) disparaît au profit de `bridge::rust_num_name` (table canonique). Sortie Rust **identique** (refactor pur sur le numérique) — c'est une **unification**, pas un changement de sémantique.
2. **Monomorphiser `ExternApp`** : `lower_type` produit déjà `path::<args>` (posé en 24000.1). Ici, **les appels** :
   - constructeur/méthode sur un récepteur `ExternApp(path, args)` → router comme `Extern` (le path est dans
     `args`-agnostique `etypes`), en **propageant** l'instanciation pour les retours `T` (cf. 2.C fournit le type).
   - arg dont le type attendu est `Generic("T")` instancié `f64` → coercition via `bridge::coerce_arg` avec la cible résolue.
3. **Migrer la coercition d'args vers `bridge::coerce_arg`** : `extern_arg`/`extern_arg_to` (non-numérique :
   `&`/`.as_ref()`/octets) consultent la **table octets/conteneurs** de `bridge` au lieu de `match Type::…` en dur.
   (⇒ B22/B27/B29 deviennent des **entrées de table**, plus du code.)

## Fichiers possédés
- **Édition exclusive** : `src/lower.rs` (`coerce_to`, `extern_arg`, `extern_arg_to`, `coerce_sized_binop`,
  `try_extern_ctor`/`try_extern_method` pour le routage `ExternApp`, `lower_type` bras numériques/ExternApp,
  `num_kind_str` supprimé).
- **Lecture seule** : `src/bridge.rs`, `src/ir.rs`. **N'édite pas** `bind.rs`/`infer/`.

## Interface produite / consommée
- **Produit** : le Rust final monomorphisé (`geo::Point::<f64>::new(2.0, 3.0)`) et la coercition table-pilotée.
- **Consomme** : `bridge::{coerce_arg, cast_numeric, rust_num_name, BYTES, CONTAINERS}`, `Type::ExternApp`,
  et (à l'unification) les types instanciés fournis par 2.C.

## Definition of Done (vérifiable)
1. **Refactor numérique prouvé neutre** : sur le corpus, le Rust généré pour les cas numériques (B10/B22/B26/B29)
   est **byte-identique** avant/après (diff vide) — l'unification ne change pas la sortie, elle dé-duplique.
2. `grep` : plus aucun `num_kind_str` ni `match (Type::Num…, Type::I64)` hors `bridge`.
3. `geo` : `Point.new(2.0, 3.0)` émet `geo::Point::<f64>::new(2.0_f64, 3.0_f64)` (ou équivalent qui compile) ; `cargo` vert.
4. Gate VERT ; 0 `unsafe` (I2) ; codegen `TokenStream` (I10).
