# [40300] Closures rendant un trait-objet / HOF avancées

- Version : V12 · Statut : draft (cadrage) · Dépend de : [24300] · Invariants : I6, I10

## Objectif
Passer une **closure qui construit/retourne un trait-objet boxé** : `eframe::run_native(name, opts,
Box::new(|cc| Ok(Box::new(MyApp::default()))))`. Iron a des closures simples (`map`/`filter`) mais pas
`Box<dyn FnOnce(&Ctx) -> Box<dyn App>>`.

## Périmètre
- Closures dont le **retour** est un `Box<dyn Trait>` (construire un objet Iron + le boxer en trait-objet).
- Le paramètre de contexte (`&CreationContext`) est un **emprunt** fourni par le crate → lié à [30200].

## Hors-périmètre
- Closures capturant un état mutable complexe (→ [35000]).

## Questions ouvertes
- ❓ Syntaxe Iron pour « rends un `MyApp` en tant que `dyn App` boxé » ?
- ❓ Forte dépendance à [24300] (le type doit implémenter le trait pour être boxé en `dyn Trait`).

## Done (cible)
`run_native(...)` avec une app Iron compile (couplé à [24300]).
