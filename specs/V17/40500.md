# [40500] Lowering : consommation uniforme de l'`OwnershipPlan` (un seul chemin)

- Version : V17
- Milestone : ownership-engine
- Statut : draft
- Dépend de : [30800] (`OwnershipPlan`), I9 (pipeline), I10 (codegen TokenStream)
- Invariants applicables : I1, I2, I10

## Objectif
Faire que `lower.rs` décide l'abaissement Rust (`&x` / `&mut x` / `x` / `x.clone()`) à **chaque** site d'usage
**uniquement** d'après l'`OwnershipPlan` ([30800]), par **un seul chemin**. Aujourd'hui chaque construct a sa
règle ad-hoc — `byref_params` (fns libres seulement), for-élément (analyse **dupliquée**), passage d'args,
codegen **opérateurs** séparé, `extern_arg` (logique `&` à part) — d'où les **incohérences** (un opérateur ne
s'autoref pas comme une méthode ; une méthode n'emprunte pas comme une fn libre). On les **subsume**.

## Périmètre
- Une fonction d'émission **unique** `emit_use(node, expr) -> TokenStream` pilotée par `plan.sites[node]` :
  `Borrow → &place`, `BorrowMut → &mut place`, `Move → value`, `Clone → value.clone()`.
- Brancher **tous** les sites dessus : args d'appel (libre/méthode/externe), récepteur, **opérateurs désucrés**,
  variable de `for`, retours, champs de struct-literal/collection, captures.

## Hors-périmètre
- Le **calcul** des dispositions (c'est [30800]). Ici on **consomme** seulement.
- Les coercions de **type** (numériques dimensionnées, octets) restent — orthogonales à l'ownership.

## Comportement attendu
**Subsomption des mécanismes actuels** (chacun devient un appel à `emit_use`) :

| Mécanisme actuel (dispersé) | Devient |
|---|---|
| `byref_params` (fns libres) + modes au site d'appel | `emit_use` sur chaque arg, via `plan.params`/`plan.sites` |
| for-élément (`for_var_borrowable`, **dupliqué**) | `plan.sites[var]` → `Borrow` ⇒ `xs.iter()` ; sinon `.iter().cloned()` |
| codegen **opérateurs** (chemin séparé) | `a OP b` désucré (cf. [30800]) → opérande émis par `emit_use` (autoref cohérent) |
| `extern_arg` (logique `&` ad-hoc) | `emit_use` + la coercion de type (séparée, conservée) |
| **modes de méthode** (absents aujourd'hui) | `plan.params["Type::m"]` consommé comme une fn libre |

```rust
// un seul point de vérité (esquisse) :
fn emit_use(&mut self, node: NodeId, x: &Expr) -> TokenStream {
    match self.plan.sites.get(&node) {
        Some(Disp::Borrow)    => { let p = self.place(x); quote!{ &#p } }
        Some(Disp::BorrowMut) => { let p = self.place(x); quote!{ &mut #p } }
        Some(Disp::Move) | None => self.value(x),
        Some(Disp::Clone)     => { let v = self.value(x); self.audit.push(x.span); quote!{ #v.clone() } }
    }
}
```

## Contrat / interface
- **Consommé** : `OwnershipPlan` ([30800]) — `sites` (par NodeId) + `params` (par fn/méthode).
- **Produit** : le même Rust qu'aujourd'hui **à l'étape de migration (a)** (neutralité prouvée), puis **meilleur**
  (emprunts cohérents) après greffe. **Décision figée** : `lower` ne lit **plus** `byref_params`/for-élément
  locaux/règles opérateurs — **uniquement** le plan.
- I10 respecté (TokenStream) ; les spans des `Clone` restants alimentent l'audit I4.

## Critères d'acceptation
- **Neutralité** : à l'étape (a), le Rust généré du corpus + raytracer est **identique** à l'actuel (diff vide).
- **Cohérence** : `a + b` (Vec3 emprunté), `obj.m(x)` (x emprunté), `f(x)` (x emprunté) passent **tous** par
  `emit_use` → comportement identique pour une même disposition (plus d'incohérence opérateur/méthode/fn).
- Corpus 80 vert ; raytracer sans clones résiduels ; 0 `unsafe`.

## Risques / questions ouvertes
- **❓ Sites sans NodeId de disposition** (expr synthétiques du désucrage) : repli `Move`/`value` (sûr).
- **🔶 Ordre de bascule** : commencer par les args (déjà semi-câblés), finir par les opérateurs (désucrage) →
  minimise le risque à chaque étape. Détail en planif.
