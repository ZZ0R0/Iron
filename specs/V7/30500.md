# [30500] Escape point-fixe (DV2) + scoping for-var (D7b)

- Version : V7 · Milestone : M2 · Statut : draft · Dépend de : 30200, 30400 · Invariants : I1, I2

## Objectif
Deux dettes d'ownership (différées V6/30400) : escape analysis **inter-signatures** par point fixe (moins
de clones), et **scoping de la variable de `for`** utilisée après la boucle.

## Périmètre
- **Point fixe (DV2)** : itérer les `ParamModes` jusqu'à stabilité — un param passé en `ByRef` à une autre
  fn ne s'échappe pas (au lieu du 1-shot conservateur actuel).
- **For-var (D7b)** : une variable de boucle lue **après** la boucle → hoistée comme locale, dernière valeur
  conservée (cf. `p_forvar.irn`, échec actuel « cannot find value `v` »).

## Hors-périmètre
- Borrow-checker complet (reste `rustc`, I2).

## Comportement attendu
- `g(p)` où `g` prend `&T` ⇒ `p` reste `ByRef` chez l'appelant (emprunt transitif, moins de clones).
- `for v in xs: …` puis `print(v)` → `v` hoistée (`let mut v = …; for __v in xs { v = __v; … }`), accessible après.

## Contrat / interface
`resolve.rs` : itération point-fixe sur `ParamModes` (jusqu'à stabilité). Collecte des **for-vars
échappantes** (lues hors corps de boucle) → hoisting (init sûr requis : itérable vide → cf. risque).
