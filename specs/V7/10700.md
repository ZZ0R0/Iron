# [10700] Affectation augmentée + opérateurs (`**`, `//`, bit-à-bit)

- Version : V7 · Milestone : M1 · Statut : draft · Dépend de : 10200 · Invariants : I1, I6, I9

## Objectif
Compléter les opérateurs : affectation augmentée (`+=`, `-=`, …) et opérateurs manquants (puissance `**`,
division entière `//`, bit-à-bit) — bases attendues, aujourd'hui absentes.

## Périmètre
- Augmentées : `+= -= *= /= %= **= //=` (+ bit-à-bit) sur var/champ/index.
- Opérateurs : `**` (puissance), `//` (division entière plancher), `& | ^ << >>` (bit-à-bit), `~` (non binaire).

## Hors-périmètre
- Surcharge d'opérateur utilisateur (→ 50700, traits) ; `@` (matmul).

## Comportement attendu
- `x += 1` → `x = x + 1;` (désucrage ; cible évaluée une fois si effet de bord → temp).
- `n ** 3` (entiers) → `n.pow(3u32)` ; `x ** 2.0` (flottants) → `x.powf(2.0)`.
- `7 // 2` → `7i64.div_euclid(2)` (plancher) ; `a & b`, `a << 2` → opérateurs Rust.

## Contrat / interface
Lexer/parser : tokens `PlusEq`…, `StarStar`, `SlashSlash`, bit-à-bit. IR : `BinOp::{Pow, FloorDiv, BitAnd,
BitOr, BitXor, Shl, Shr}` ; augmentées **désucrées au parser** (`x op= e` → `Assign(x, Binary(op, x, e))`).
`lower` : `pow`/`powf`/`div_euclid`/opérateurs. Cible augmentée à effet de bord → `let` temporaire.

## Source maps
Marqueur instruction sur l'`Assign` désucré.

## Critères d'acceptation
- `x = 5 ; x += 3 ; print(x)` → 8 ; `print(2 ** 10)` → 1024 ; `print(7 // 2)` → 3 ; `print(6 & 3)` → 2.
- Augmentée sur `xs[i] += 1` et `p.f += 1` compilent ; corpus inchangé.

## Décomposition
→ planif : lexer/parser (tokens + désucrage), IR (BinOp), lower.

## Risques / questions ouvertes
- 🔶 `**` exposant entier ⇒ `u32` requis par `pow` — caster le littéral.
- 🔶 `//` sur flottants = `div_euclid` aussi (`f64::div_euclid`) — cohérence à figer.
