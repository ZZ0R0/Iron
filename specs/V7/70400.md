# [70400] `ironc new` — scaffolding de projet

- Version : V7 · Milestone : M4 · Statut : draft · Dépend de : 70300 · Invariants : I9

## Objectif
Commande `ironc new <nom>` créant un squelette de projet prêt à compiler — ergonomie de démarrage (à la
`cargo new`).

## Périmètre
- `ironc new demo` → dossier `demo/` avec `ironc.toml` + `src/main.irn` (« hello world ») + `.gitignore`.
- `ironc new --lib demo` → squelette bibliothèque (optionnel).

## Hors-périmètre
- Templates personnalisés ; init git (V8).

## Comportement attendu
- `ironc new demo` → arborescence :
  ```
  demo/ironc.toml
  demo/src/main.irn   (fn main(): print("hello from Iron"))
  demo/.gitignore     (/target, /ironc-out)
  ```
- `cd demo && ironc run` → `hello from Iron`.

## Contrat / interface
`main.rs` CLI : sous-commande `new <nom> [--lib]` → écrit les fichiers gabarits. Réutilise le schéma
manifeste (70300).
