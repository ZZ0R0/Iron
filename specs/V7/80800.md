# [80800] Stdlib : `datetime`, `random`, `regex`, `os` / `env` / `process`

- Version : V7 · Milestone : M6 · Statut : draft · Dépend de : 80300, 50600 · Invariants : I5, I7, I13

## Objectif
Modules système courants — temps, aléatoire, regex, environnement — tous absents. Wrappers `std` + crates
curées (D2/D5).

## Périmètre
- `os.env(name) -> Option[str]`, `os.args() -> list[str]`, `os.exit(code)` ; `process.run(cmd, args) -> str`.
- `time.now_secs() -> i64`, `time.sleep_ms(n)` (via `std::time`/`std::thread`).
- `random.int(a, b)`, `random.float()` (via crate `rand`, `.iri` curé).
- `regex.match(pat, s) -> bool`, `regex.find_all(pat, s) -> list[str]` (via crate `regex`).

## Hors-périmètre
- Fuseaux horaires/datetime riche (chrono, V8) ; regex compilées réutilisables (V8) ; sous-process interactifs.

## Comportement attendu
- `os.env("HOME")` → `std::env::var("HOME").ok()` (Option, I11).
- `time.now_secs()` → `std::time::SystemTime::now()…as_secs() as i64`.
- `random.int(1, 6)` → `rand::thread_rng().gen_range(1..=6)` ; `regex.match(r"\d+", s)` → `Regex::new(...)?.is_match(s)`.

## Contrat / interface
Modules namespacés (D2) `os`/`time`/`random`/`regex`/`process`. `os`/`time`/`process` = `std` (sans dep) ;
`random`/`regex` = crates curées (`.iri`, 50600). Faillible → `Result`/`IronError` (I13).

## Critères d'acceptation
- `os.env`/`os.args` ; `time.now_secs` ; `random.int(1,6)` ∈ [1,6] ; `regex.match(r"\d+","a1")` → true.
- Modules `std`-only marchent sans dep ; `random`/`regex` nécessitent la dep déclarée.
