# [80400] Stdlib : JSON (`json`)

- Version : V7 · Milestone : M5 · Statut : draft · Dépend de : 80300, 50600, 80500 · Invariants : I7, I11, I13

## Objectif
Module `json` (parse/sérialise) — indispensable et absent. Wrapper sur la crate **`serde_json`** (D2/D5,
`.iri` curé).

## Périmètre
- `json.parse(s) -> Value` (type `Value` dynamique) ; accès `v["clé"]`, `v[0]`, `to_i64`/`to_str`/… ;
  `json.to_json(x) -> str` pour les types Iron sérialisables.

## Hors-périmètre
- Dérivation `Serialize`/`Deserialize` automatique de structs Iron (V8) ; JSON streaming.

## Comportement attendu
- `json.parse("{\"a\": 1}")` → `serde_json::from_str::<serde_json::Value>("…")?`.
- `v["a"].to_i64()` → accès + conversion ; `json.to_json([1,2,3])` → `serde_json::to_string(&…)?` → `"[1,2,3]"`.

## Contrat / interface
`[dependencies] serde_json` (70300) + `bindings/serde_json.iri` curé. Type opaque `Value` (`extern type`,
50400) + fns d'accès/conversion bindées. Faillible → `Result`/`IronError` (I11/I13).

## Critères d'acceptation
- `json.parse` d'un objet + accès champ → valeur correcte ; `json.to_json` d'une liste → chaîne JSON valide.
- JSON malformé → `IronError` ; nécessite la dep déclarée (50600).
