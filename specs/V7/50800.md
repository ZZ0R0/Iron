# [50800] Forme indentée `rust:`

- Version : V7 · Milestone : M4 · Statut : draft · Dépend de : 50100 · Invariants : I7, I8

## Objectif
Compléter l'inclusion Rust (différé V6/50400) : forme **indentée** `rust:` en plus de `rust { … }`, pour
des blocs Rust qui suivent le style off-side d'Iron.

## Périmètre
- `rust:` suivi d'un bloc **indenté** capturé brut (équivalent `rust { … }`) ; capture sautant `/* */`,
  chaînes et `'{'`.

## Hors-périmètre
- `rust:` en position d'**expression** retournant une valeur (V8 ; aujourd'hui `rust` = instruction).

## Comportement attendu
- ```
  rust:
      let x = 5;
      println!("{}", x);
  ```
  équivaut à `rust { let x = 5; println!("{}", x); }` → texte verbatim émis.

## Contrat / interface
Lexer : après `rust`, si `:` + Newline + Indent → **capturer les lignes indentées brutes** jusqu'au Dedent
(au niveau du `rust`). Émettre `TokenKind::RustVerbatim` (existant). Parser/lower inchangés (RustBlock).

## Source maps
Erreur dans le bloc `rust:` → `Span` du bloc (I8), comme `rust { }`.

## Critères d'acceptation
- Un `rust:` indenté multi-lignes compile + s'exécute, identique à son équivalent `rust { }`.
- Imbrication accolades/chaînes dans le bloc préservée ; corpus inchangé.

## Décomposition
→ planif : capture lexer indentée (réutilise `skip_rust_string`), tests d'équivalence.

## Risques / questions ouvertes
- 🔶 Capture indentée brute vs machine off-side du lexer — lire les octets de ligne sans ré-indenter.
