# [70600] `ironc fmt` — formateur Iron

- Version : V7 · Milestone : M7 · Statut : draft · Dépend de : 10200 · Invariants : I9

## Objectif
Un **formateur** canonique pour `.irn` (à la `rustfmt`/`black`) : indentation, espaces, lignes — cohérence
de style, aujourd'hui absente.

## Périmètre
- `ironc fmt <fichier|projet>` réécrit en style canonique : indentation 4 espaces, un espace autour des
  opérateurs binaires, pas d'espace avant `:`, lignes vides normalisées. `--check` (ne réécrit pas, code retour).

## Hors-périmètre
- Réorganisation sémantique ; largeur de ligne/wrapping intelligent (V8) ; tri d'imports.

## Comportement attendu
- Entrée mal espacée `x=1+2` → `x = 1 + 2` ; indentation tabs → 4 espaces ; `fn  f( a:i64 )` → `fn f(a: i64)`.
- Idempotent : `fmt(fmt(x)) == fmt(x)`.

## Contrat / interface
Pretty-printer sur l'**AST** (réutilise lexer/parser) → source `.irn` canonique. `main.rs` : sous-commande
`fmt [--check]`. **Préserve la sémantique** (re-parse identique).

## Source maps
N/A (transformation source→source).

## Critères d'acceptation
- `ironc fmt` d'un fichier mal formaté → sortie canonique ; **idempotent** ; re-parse == AST d'origine.
- `--check` retourne code ≠ 0 si non formaté ; tout le corpus est `fmt`-stable après une passe.

## Décomposition
