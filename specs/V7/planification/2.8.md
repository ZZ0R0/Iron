# [2.8] Variantes d'enum à champs nommés

- Spec parente : 21000 · Version : V7 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
`enum E: V(a: i64, b: str)` → struct-variant Rust ; construction + motif par nom.

## Fichiers touchés
`src/parse.rs` (decl champs nommés, construction, motif), `src/infer/mod.rs` (`variant_field_types` par nom), `src/lower.rs` (struct-variant + motif `V{…}`).

## Étapes
1. Parser : variante `V(a: T, b: U)` (noms) ; construction `E.V(a=…, b=…)` ; motif `E.V(a, b)`/`E.V(a=pa)`.
2. Infer : champs de variante par nom.
3. Lower : `enum { V { a: T, b: U } }` ; `E::V { a: …, b: … }` ; motif `E::V { a, b }`.

## Critère de done
`Shape.Rect(w=3.0, h=4.0)` + `match … Rect(w, h)` → aire 12.0 ; variantes tuple **et** nommées coexistent ; corpus inchangé.

## Notes
