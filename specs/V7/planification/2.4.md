# [2.4] Affectation augmentée + opérateurs (`**`, `//`, bit-à-bit)

- Spec parente : 10700 · Version : V7 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
`+=`…`//=`, `**`, `//`, `& | ^ << >> ~`.

## Fichiers touchés
`src/lex.rs` (tokens), `src/parse.rs` (désucrage `op=` → Assign(Binary), opérateurs), `src/lower.rs` (`pow`/`div_euclid`/ops).

## Étapes
1. Lexer : `PlusEq`…, `StarStar`, `SlashSlash`, bit-à-bit, `~`.
2. Parser : `x op= e` → `Assign(x, Binary(op, x, e))` (cible à effet de bord → temp) ; `BinOp::{Pow,FloorDiv,Bit*}`.
3. Lower : `**` → `pow(u32)`/`powf` ; `//` → `div_euclid` ; bit-à-bit → ops Rust.

## Critère de done
`x += 3` → 8 ; `2 ** 10` → 1024 ; `7 // 2` → 3 ; `6 & 3` → 2 ; augmentée sur `xs[i]`/`p.f` ; corpus inchangé.

## Notes
`pow` exige exposant `u32` → caster. `**` flottant → `powf`.
