# [2.7] Compréhensions liste / dict / set

- Spec parente : 10600 · Version : V7 · Dépend de : 2.1 (tuples), 2.6 (set) · Statut : todo · **Vague 2**

## But
`[f(x) for x in xs if p(x)]`, dict/set.

## Fichiers touchés
`src/parse.rs` (syntaxe `for…in…if`), `src/infer/local.rs` (type collection), `src/lower.rs` (itérateurs).

## Étapes
1. Parser : après 1ʳᵉ expr, `for var in iter [if cond]` → `ExprKind::Comp{kind,…}` (kind via `[]`/`{}`/`{:}`).
2. Infer : type de collection depuis body/iter.
3. Lower : `iter.into_iter().filter(…).map(…).collect::<Vec|HashMap|HashSet>()` (réutilise closures 20700).

## Critère de done
`[x*x for x in [1,2,3]]`→`[1,4,9]` ; `[x for x in range(5) if x%2==0]`→`[0,2,4]` ; dict/set compréhension ; corpus inchangé.

## Notes
`{…:…}`→dict, `{…}`→set, `[…]`→list. Filtre `if` sur copie de l'élément (robuste).
