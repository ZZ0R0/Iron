# [4.4] Itertools (enumerate/zip/reduce/sorted/any/all)

- Spec parente : 80700 · Version : V7 · Dépend de : 1.1, 2.1 (tuples) · Statut : todo · **Vague 4**

## But
`enumerate`, `zip`, `reversed`, `any`, `all`, `reduce(f, xs, init)`, `sorted(xs[, key=f])`.

## Fichiers touchés
`src/lower.rs` (built-ins → chaînes d'itérateurs), `src/infer/local.rs` (retours list de tuples).

## Étapes
1. `enumerate`→`.enumerate().map(|(i,x)|(i as i64,x))`, `zip`→`.zip()`, `reversed`→`.rev()`.
2. `any`/`all`→`.any()/.all()` ; `reduce`→`.fold(init, f)`.
3. `sorted`→clone+`sort` ; `sorted(key=f)`→`sort_by_key`.

## Critère de done
`enumerate(["a","b"])`→`[(0,"a"),(1,"b")]` ; `zip([1,2],[3,4])` ; `reduce(+,[1,2,3,4],0)`→10 ; `sorted` ; corpus inchangé.

## Notes
`key=` = argument nommé (sucre parser : closure par nom). Retours tuple → dépend 2.1.
