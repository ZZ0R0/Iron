# [2.3] Zoo numérique + `char`

- Spec parente : 20800 · Version : V7 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
Tous les numériques Rust par annotation + `char` ; défauts i64/f64 inchangés.

## Fichiers touchés
`src/parse.rs` (`parse_type` : zoo + `char`, littéral `'a'`), `src/lower.rs` (`lower_type` map, casts), `src/infer/local.rs` (`to_u32`…).

## Étapes
1. Parser : `parse_type` reconnaît i8…u128/usize/isize/f32 → `Type::Num(NumKind)`, `char` → `Type::Char`, littéral `'a'`.
2. Lower : `lower_type` mappe chaque NumKind/Char ; `is_copy` inclut tous ; casts `to_u32(x)` → `(x as u32)`.
3. Infer : annotation prime ; built-ins de conversion.

## Critère de done
`n: u32 = 5`, `i: usize = len(xs)`, `c: char = 'z'` compilent + s'exécutent ; corpus inchangé (défauts i64/f64).

## Notes
Ambiguïté `{integer}` : suffixer le littéral à la cible annotée. Overflow = défaut rustc (I2).
