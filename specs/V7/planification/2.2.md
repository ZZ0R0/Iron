# [2.2] f-strings

- Spec parente : 10500 · Version : V7 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
Interpolation `f"…{expr}…"` → `format!`.

## Fichiers touchés
`src/lex.rs` (préfixe `f"…"` → capture des parts), `src/parse.rs` (sous-expressions), `src/lower.rs` (`format!`).

## Étapes
1. Lexer : reconnaître `f"…"`, découper en parts littérales + sous-sources `{…}` (accolades équilibrées, `{{`/`}}`).
2. Parser : re-parser chaque sous-source en `Expr` → `ExprKind::FString`.
3. Lower : `format!("…{}…", args…)` (I10).

## Critère de done
`f"{name} a {age} ans"` → `Iron a 1 ans` ; `f"{a+b}"` → `5` ; `f"{{x}}"` → `{x}` ; corpus inchangé.

## Notes
Accolades imbriquées (dict/set dans `{…}`) → capture équilibrée. Display par défaut.
