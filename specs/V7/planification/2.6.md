## But
`set[T]`, littéral `{1,2,3}`, `add`/`in`/`|`/`&`/`-`.

## Fichiers touchés
`src/parse.rs` (littéral `{…}` set vs dict via `:`), `src/infer/local.rs` (`set[T]`), `src/lower.rs` (`HashSet` + ops).

## Étapes
1. Parser : `{…}` sans `:` → set littéral ; `set([…])` ; `set[T]` type.
2. Infer : `Type::Set` ; `add`→Unit, `in`→Bool.
3. Lower : `HashSet::from([…])` ; `s.insert` ; `&a | &b`/`&a & &b`/`&a - &b` (dispatch set).

## Critère de done
