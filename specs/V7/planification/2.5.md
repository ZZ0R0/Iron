# [2.5] Ternaire / `in` / `assert` / slicing

- Spec parente : 10800 · Version : V7 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
`a if c else b`, `x in/not in coll`, `assert cond[, msg]`, `xs[a:b]`.

## Fichiers touchés
`src/parse.rs` (ternaire/slice/assert), `src/infer/local.rs` (types), `src/lower.rs` (if-expr/contains/assert!/slice).

## Étapes
1. Parser : `a if c else b` → `Ternary` ; `in`/`not in` → `BinOp` ; `assert` → `StmtKind::Assert` ; `xs[a:b]` → `Slice`.
2. Infer : ternaire = type branches ; `in` → Bool ; slice = type base.
3. Lower : `if/else` expr ; `contains`/`contains_key` ; `assert!` ; `[a..b].to_vec()`/`.to_string()`.

## Critère de done
ternaire, `3 in [1,2,3]`→true, `assert`, `[10,20,30][0:2]`→`[10,20]` compilent + s'exécutent ; corpus inchangé.

## Notes
`assert` échoué porte le `Span` Iron (I8). Slice str non-UTF8 → panic (filet I2).
