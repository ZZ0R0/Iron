## But
Appel de fns Rust génériques mono-instanciées ; `impl Display/Iterator/From for T` côté Iron.

## Fichiers touchés
`src/parse.rs` (`impl Trait-std for T`), `src/lower.rs` (impl Rust idiomatique), `src/bind.rs` (fns génériques mono-usage).

## Étapes
1. Parser/IR : `impl <Trait std> for <Type>` + mapping méthodes-trait (`Display::fmt`, `Iterator::next`).
2. Lower : `impl std::fmt::Display for T { fn fmt(&self, f) { write!(…) } }`, etc.
3. Bind : fns génériques mono-usage.

## Critère de done
