# 2.1 — Prélude d'idiomes Iron (combler avant le fan-out)

> Vague 2, **séquentiel** (modifie `ironc/src`). But : pour que le `.irn` soit **le même code** que le `.py`
> (PS utilisateur), Iron doit accepter les idiomes débutant **communs** aux 30 programmes. On les comble
> **avant** le fan-out → aucune piste 3.x/4.x n'a à toucher `ironc/src` (parallélisme sûr). Possède :
> `ironc/src/**` (cette vague uniquement) + `tests/v11-test/idioms/` (probes).

## Cibles (vérifier l'état, puis combler si manquant)

Confirmés **trous** en cadrage (à combler) :
1. **`s.split()` sans argument** → split sur whitespace (Python : strip + split sur runs d'espaces).
   *(wc, wordfreq, anagram, csvsum)*
2. **Slice négatif** `xs[-n:]`, `xs[:-n]`, `s[-1]` → indices Python (depuis la fin), pas de panic.
   *(rle, editdist, divers)*
3. **`sep.join(xs)`** (forme **méthode**) → aujourd'hui seul `join(xs, sep)` existe. *(sortie partout)*

À **vérifier puis combler si absent** (probes) :
4. **`ord(c)` / `chr(n)`** — char ↔ code. *(cksum, od, histogram, tr)*
5. **`s.count(sub)`** — nombre d'occurrences. *(wc, grep)*
6. **`s.splitlines()`** — découpe sur fins de ligne (gère `\n` final). *(tout le texte)*
7. **`min(...)` / `max(...)`** builtins (liste ou variadique). *(histogram, collatz, wordfreq)*
8. **`abs(n)`**, **`sum(xs)`** builtins. *(editdist, dotproduct, csvsum)*
9. **`s[i]`** indexation char + `for c in s` (déjà ?) + **bytes ASCII** via `ord`. *(od, cksum)*

> Règle stricte : on comble **l'idiome Python**, fidèlement, **sans imposer d'annotation** (l'inférence
> V10/V11 doit tenir). Chaque ajout est un lowering builtin (comme `upper`/`split(sep)` existants) — **pur
> langage**, pas de stdlib Iron.

## Méthode

Pour chaque idiome : un **probe** `tests/v11-test/idioms/<idiome>.irn` (+ l'équivalent Python mental) qui
**doit compiler et donner le même résultat que Python**. Si trou → fix minimal dans `ironc/src`
(`lower.rs` builtins / `parse.rs` / slicing). Non-régression : `gate-v11.sh` (langage) reste **VERT**.

## Interface produite

Un **socle d'idiomes** sur lequel les 30 `.irn` s'écrivent **comme le `.py`**. Au-delà de cette liste, tout
idiome **non prévu** rencontré en fan-out est **noté** (pas corrigé en parallèle) et traité en touch-up
séquentiel (vague 5).

## Definition of Done

- Les probes 1–9 (ceux réellement nécessaires) **compilent + matchent Python**, **0 annotation**.
- `gate-v11.sh` (langage Iron) **VERT** (aucune régression des features V11).
- Liste des idiomes **réellement comblés** vs **déjà présents** consignée dans `realisation.md`.
