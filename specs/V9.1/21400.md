# [21400] Génériques utilisateur complets

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 20300 · Invariants : I6

## Objectif
Compléter les **génériques utilisateur** : aujourd'hui Iron a `Type::Generic`/`App` (V3/20300) mais les
fonctions/structs génériques **à bornes** sont limitées. Permettre `def f[T](x: T) -> T`, `class Box[T]`,
bornes `[T: Display]` → génériques/bornes Rust (projection propre, I6).

## Périmètre
- **Fns génériques** : `def map_all[T, U](xs: list[T], f: fn(T) -> U) -> list[U]` → `fn map_all<T, U>(…)`.
- **Structs/enums génériques** : `class Box[T]: value: T` → `struct Box<T> { value: T }`.
- **Bornes** : `[T: Display]`, `[T: Clone]` → `<T: Display>`. Projection des traits-protocoles (51600).
- **Inférence d'appel** : `f([1,2,3])` → `T=i64` (depuis l'argument), monomorphisation par rustc.

## Hors-périmètre
- Inférence HM globale (0.1%, 90600) — on reste sur l'inférence locale + dirigée par l'usage.
- Bornes de traits custom non-bénis (→ shims).

## Comportement attendu
```
class Pair[A, B]:
    first: A
    second: B
def swap[A, B](p: Pair[A, B]) -> Pair[B, A]:
    return Pair(first=p.second, second=p.first)
```
→ `struct Pair<A, B> { … }`, `fn swap<A, B>(p: Pair<A, B>) -> Pair<B, A> { … }`.

## Contrat / interface
`parse` : params de type `[T, U]` + bornes. `ir.rs` : `Generics` étendu (bornes). `infer` : substitution
locale + inférence depuis l'usage. `lower` : `<T: Bound>` (I10).

## Source maps
I8 : les appels génériques portent leur `Span` ; une erreur de borne rustc remonte au `Span` Iron (60800).

## Critères d'acceptation
- Fns/structs/enums génériques à bornes → Rust idiomatique, compile + s'exécute (tests).
- `f([1,2,3])` infère `T` correctement (monomorphisation).
- Borne non satisfaite → erreur claire (Span Iron via overlay 60800).

## Décomposition
→ planif `D1` : params de type + bornes (parse/IR), inférence locale, lowering génériques, tests.

## Risques / questions ouvertes

  solveur global).
