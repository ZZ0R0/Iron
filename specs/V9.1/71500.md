# [71500] Extension VSCode : langage `.irn`/`.iri`, icônes, association

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : — · Invariants : I14

## Objectif
Le socle de l'expérience dev : une **extension VSCode** qui fait reconnaître Iron par l'éditeur — fichiers
`.irn`/`.iri` identifiés comme langage `iron`, **icônes** dans l'explorateur, configuration de base. Sans ça,
un `.irn` est un fichier texte anonyme.

## Périmètre
- **Squelette d'extension** : `extensions/vscode/` (`package.json` manifest, `language-configuration.json`).
- **Déclaration de langage** `iron` : `contributes.languages` avec extensions `.irn` (source) et `.iri`
  (bindings), aliases, `configuration` (commentaires `#`, paires de brackets, indentation off-side).
- **Icônes de fichier** : `contributes.iconThemes` ou file-icon associé (logo Iron pour `.irn`/`.iri`).
- Empaquetage `.vsix` (installable localement) ; instructions d'install.

## Hors-périmètre
- Coloration (71600), LSP (71700), imports (71800), build (71900) — chantiers séparés, même extension.

## Comportement attendu
Dans VSCode : ouvrir un `.irn` → la barre d'état indique « Iron » ; l'explorateur montre une **icône Iron** ;
`#` commente, l'auto-indentation suit l'off-side rule.

## Contrat / interface
`extensions/vscode/package.json` : `contributes.languages` + `iconThemes`/icône. `language-configuration.json`
: commentaires, brackets, indentation. Build : `vsce package` → `.vsix`.
