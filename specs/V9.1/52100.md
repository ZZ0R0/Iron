# [52100] `import <crate>` auto-bind complet (rustdoc à la volée + cache)

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 50300, 50900, 70700 · Invariants : I7

## Objectif
Faire de `import <crate>` l'**import universel** : si aucun `.iri` curé n'existe, lancer **`ironc bind`
automatiquement** (rustdoc-json), **mettre en cache** le `.iri`, et l'utiliser — le tout transparent. Finit
70700 (qui ne charge qu'un `.iri` local). C'est ce qui rend « tout par import » réellement utilisable.

## Périmètre
- `import regex` → résolution : (1) `regex.irn` (module Iron) ; (2) `.iri` curé (registre 52300) ; (3)
  **auto-bind** : `ironc bind regex` → `target/iron-bindings/regex-<version>.iri`, mis en cache.
- **Cache** : clé = crate + version (depuis `ironc.toml`) ; re-bind seulement si la version change.
- **Version** : résolue via `ironc.toml` (`[dependencies]`).
- Échec de bind (rustdoc indispo / crate trop complexe) → message clair + suggestion `.iri` curé.

## Hors-périmètre
- Le registre curé (52300) ; `import std` (52200, cas spécial).

## Comportement attendu
```
# ironc.toml : [dependencies] regex = "1"
import regex
def main():
    r = Regex.new("[0-9]+")
    ...
```
1ʳᵉ compilation : « binding de regex… » (rustdoc), cache écrit. 2ᵉ : cache hit, instantané.

## Contrat / interface
`driver` : résolveur d'import à 3 niveaux + cache `target/iron-bindings/`. `bind` invoqué en sous-processus.
`ironc.toml` fournit la version.

## Source maps
N/A (résolution d'import) ; les appels lowerés gardent leur `Span`.

## Critères d'acceptation
- `import regex` (regex dans `ironc.toml`, sans `.iri`) → auto-bind + compile + run, **sans** `bind`/`use`.
- 2ᵉ build : pas de re-bind (cache hit) ; changement de version → re-bind.
- Crate sans rustdoc-json exploitable → erreur claire orientant vers `.iri` curé.

## Décomposition
→ planif `A2` : résolveur 3-niveaux, cache, intégration `ironc.toml`, message d'échec.

## Risques / questions ouvertes
- 🔶 Latence du 1ᵉʳ import (rustdoc lent + nightly requis) → message + cache agressif ; nightly absent → dégrader.
- 🔶 Couverture variable selon le crate (cf. mesure V8 : 62–92 %) → le registre curé (52300) couvre les durs.
