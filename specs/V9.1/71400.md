# [71400] `ironc fmt` : formateur canonique avec préservation des commentaires

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 10100, 10200 · Invariants : I9

## Objectif
Donner à Iron son **formateur** (différé V7/V9). Bloqueur historique : le lexer **jette les commentaires** ;
un fmt qui les perd est inacceptable. Cette spec ajoute la **préservation des trivia** (commentaires) au lexer
+ le pretty-printer AST→source canonique.

## Périmètre
- **Lexer** : émettre les commentaires comme **trivia** attachés (token `Comment` ou trivia rattachée au nœud
  suivant), au lieu de les sauter.
- **Pretty-printer** : AST (+ trivia) → source canonique (indentation 4, espaces autour des opérateurs/`=`,
  lignes vides normalisées) ; **commentaires préservés** à leur position.
- **`ironc fmt [--check]`** : reformate en place / vérifie (CI). Idempotent : `fmt(fmt(x)) == fmt(x)`.

## Hors-périmètre
- Réorganisation sémantique (tri des imports) ; configuration (un seul style canonique, façon `gofmt`).

## Comportement attendu
`x=f( a,b ) # note` → `x = f(a, b)  # note` ; indentation/lignes vides normalisées ; commentaires intacts.

## Contrat / interface
`lex` : trivia commentaires. `fmt.rs` : `format(src) -> String` (AST+trivia → source). CLI `ironc fmt`.
Le LSP (71300) peut l'appeler pour le formatage du document.

## Critères d'acceptation
- Idempotent sur tout le corpus ; **sémantique inchangée** (corpus vert après `fmt`).
- **Commentaires préservés** (test dédié : commentaires en tête, en ligne, en bloc).
