# [71800] Gestionnaire d'imports VSCode (via les imports Rust)

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 71700, 52100, 52300 · Invariants : I7

## Objectif
Rendre l'**import de crates Rust** fluide depuis VSCode — puisque c'est *le* mécanisme d'écosystème d'Iron
(D1). Quick-fix « importer `regex` », commande `ironc add`, et auto-import des méthodes de crates connus.

## Périmètre
- **Commande `Iron: Add crate`** : palette → saisir un nom → exécute `ironc add <crate>` (52300) → met à jour
  `ironc.toml` + le `.iri`.
- **Quick-fix d'import** : sur un symbole inconnu (`Regex` non importé) → action « ajouter `import regex` »
  (et `ironc add regex` si absent d'`ironc.toml`).
- **Complétion d'import** : `import <curseur>` → liste des crates du registre (52300) + d'`ironc.toml`.
- **Organisation** : commande « trier/nettoyer les imports » (optionnel).

## Hors-périmètre
- La résolution/binding elle-même (52100/52300) ; le build (71900).

## Comportement attendu
Taper `Regex.new(...)` sans import → ampoule « importer regex » → insère `import regex` (et `ironc add regex`
si besoin). `import re|` → complétion propose `regex`, `regex_syntax`…

## Contrat / interface
`extensions/vscode/` : commandes + code-actions (quick-fix) appelant la CLI `ironc add` / éditant le fichier.
S'appuie sur le registre (52300) pour la liste des crates.
