# [4.2] Erreurs typées `Result[T, E]`

- Spec parente : 21500 · Version : V9.1 · Dépend de : 4.1 · Statut : todo · **Vague 4** (séquentiel — infer/lower)

## But
`Result[T, E]` avec `E` concret (enum/type) ; `?`/`try`/`raise` propagent `E` ; défaut `IronError` (rétro-compat).

## Fichiers touchés
`src/parse.rs` (`Result[T,E]`) · `src/ir.rs` (Result 2 types) · `src/infer/flow.rs` (E inféré/annoté) · `src/lower.rs` (`Result<T,E>`, `?` + `Into`).

## Étapes
1. Syntaxe `Result[T, E]` ; IR.
2. Flux : `E` déduit des `raise`/`?` ou annoté ; défaut `IronError`.
3. Désucrage `?`/`try`/`raise` typés ; conversion `Into` sur `?`.

## Critère de done
`Result[T, E]` (E = enum) compile + propage E ; rétro-compat `Result[T]` = `Result[T, IronError]` ; mismatch E → erreur.
