# [21600] Closures avancées (stockées, retournées, captures)

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 20700, 21400 · Invariants : I2, I6

## Objectif
Lever la limite « closures inline only » : permettre de **stocker** une closure (champ de struct, variable),
de la **retourner** (`-> fn(...)`), et des captures non triviales — projetées vers `Box<dyn Fn>`/`impl Fn`
Rust. Aujourd'hui les lambdas ne servent qu'en argument de `map`/`filter`/`spawn`.

## Périmètre
- **Type fonction de 1ʳᵉ classe** : `fn(A) -> B` comme type de variable/champ/retour (déjà `Type::Fn`, à
  matérialiser).
- **Closure retournée** : `def adder(n: i64) -> fn(i64) -> i64: return lambda x: x + n` → `-> impl Fn(i64)
    -> i64` (ou `Box<dyn Fn>`).
- **Closure stockée** : `class Handler: callback: fn(i64) -> unit` → `Box<dyn Fn(i64)>`.
- **Captures** : par valeur (`move`) selon l'usage (escape) ; cohérent avec le résolveur (I2).

## Hors-périmètre
- `FnMut`/`FnOnce` fins, closures async → best-effort / `rust { }`.

## Comportement attendu
```
def multiplier(k: i64) -> fn(i64) -> i64:
    return lambda x: x * k
def main():
    triple = multiplier(3)
    print(triple(5))      # 15
```
→ `fn multiplier(k) -> impl Fn(i64) -> i64 { move |x| x * k }`.

## Contrat / interface
`infer` : `Type::Fn` matérialisé (retours/champs) ; `lower` : `impl Fn`/`Box<dyn Fn>` selon position (retour →
`impl Fn` ou boxed ; champ → boxed). Captures `move` via escape analysis.

## Source maps
I8 : la closure et son appel portent leur `Span` ; erreurs de capture/lifetime rustc remontées (60800).

## Critères d'acceptation
- Closure retournée + appelée (`multiplier(3)(5)`=15) compile + s'exécute.
- Closure stockée en champ de struct, appelée plus tard.
- 0 `unsafe`.

## Décomposition
→ planif `D3` : type `fn(...)` matérialisé, closure retournée (`impl Fn`), closure stockée (`Box<dyn Fn>`), captures, tests.

## Risques / questions ouvertes
- 🔶 `impl Fn` (retour) vs `Box<dyn Fn>` (champ/collection) → choisir selon la position ; documenter.
- 🔶 Lifetimes des captures par référence → privilégier `move` (par valeur, I2 filet).
