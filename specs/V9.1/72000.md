# [72000] `ironc repl` : éval incrémental

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 40100, 70100 · Invariants : I9

## Objectif
Un REPL Iron (`ironc repl`) pour l'exploration interactive. Approche pragmatique (Iron n'a pas
d'interpréteur, I9) : **compile-and-run** par snippet, état accumulé.

## Périmètre
- Boucle lecture-éval-affichage : items (`def`/`class`) accumulés au top-level ; statements accumulés dans un
  `main` ; une **expression** seule → affichée.
- À chaque ligne : recompile le programme accumulé + la nouvelle ligne, exécute, affiche **seulement la
  nouvelle sortie** (diff vs run précédent).
- Erreur sur une ligne → message + **rollback** de l'accumulateur (session préservée).

## Hors-périmètre
- Hot-reload / état mémoire persistant (on recompile ; coût accepté).
- Complétion (→ LSP).

## Comportement attendu
```
>>> x = 21
>>> x * 2
42
>>> def sq(n: i64) -> i64: return n * n
>>> sq(x)
441
```

## Contrat / interface
`repl.rs` : accumulateur items + body, ré-émission, capture sortie (diff), rollback sur erreur. CLI `ironc repl`.

- Ligne fautive → erreur, session préservée (rollback).
