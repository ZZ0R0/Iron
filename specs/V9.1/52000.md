# [52000] Principe « aucune bibliothèque Iron » + conversion des pseudo-modules

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 50900, 70200 · Invariants : I5, I6, I7

## Objectif
Figer la philosophie de V9.1 (D1) : **Iron ne livre aucun code de bibliothèque.** Les seules choses
« intégrées » sont les **primitives de langage** (codegen pur). Tout le reste vient d'un **import de crate
Rust**. Conséquence concrète : les pseudo-modules `io`/`os`/`time` (V7, codés en wrappers `std` spéciaux dans
`lower`) sont **retirés du compilateur** et remplacés par des **imports** (`import std`, 52200) ou des `.iri`
curés (52300).

## Périmètre
- **Définir la frontière** : primitives de langage (codegen, restent) vs bibliothèque (import, sort).
  - Restent (codegen) : `print`, `len`, `range`, `sum`/`min`/`max` sur littéraux, opérateurs, `str()`/casts,
    compréhensions, f-strings, `for`/`while`/`match`, tuples/list/dict/set **comme types du langage**.
  - Sortent (→ import) : `io`/`os`/`time` (lower_io/os/time), tout futur module utilitaire.
- **Retrait** des dispatchs `lower_io`/`lower_os`/`lower_time` ; les programmes qui les utilisaient passent par
  `import std` (52200) ou un `.iri` curé.
- **Documentation** du principe dans le `generator.md`/CLAUDE.md (contrat figé).

## Hors-périmètre
- Le mécanisme d'import lui-même (52100/52200) ; le registre (52300).

## Comportement attendu
Avant : `io.read_file(path)` (module Iron spécial). Après : `import std` puis `std.fs.read_to_string(path)`
(ou un `.iri` curé `fs.iri`). **Plus aucun module utilitaire codé en dur dans `lower`.**

## Contrat / interface
`lower` : suppression de `lower_io`/`lower_os`/`lower_time` et de leur dispatch. `generator.md` : section
« primitives vs import » figée. Les fixtures/projets utilisant io/os/time migrés vers `import std`.

## Critères d'acceptation
- Aucun module utilitaire Iron n'est codé en dur dans `lower` (grep : plus de `lower_io/os/time`).
- Les programmes V7 utilisant io/os/time **compilent toujours** après migration vers `import std`/`.iri`.
- Le contrat « zéro lib Iron » est écrit dans `generator.md`.

## Risques / questions ouvertes
- 🔶 Régression : des projets de la batterie utilisent peut-être io/os/time → migrer chaque usage (compté).
- 🔶 Frontière primitive/lib : `sorted`/`zip`/`enumerate` (itertools) — primitives ou import ? **Proposé** :
  restent primitives (sucre de langage sur itérateurs Rust), pas une « lib ».
