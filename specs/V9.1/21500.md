# [21500] Erreurs typées `Result[T, E]`

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 20200, 40400 · Invariants : I11, I13

## Objectif
Lever la limite I13 (« type d'erreur unifié `IronError` au v0 ») : permettre un **`E` concret** dans
`Result[T, E]` — enums d'erreur, erreurs de domaine — au-delà de l'`IronError` fourre-tout. Maturité attendue
d'un langage qui veut gérer les erreurs sérieusement.

## Périmètre
- **Syntaxe** : `Result[T, E]` (deux paramètres) ; `E` peut être un enum Iron, un type externe, ou `IronError`.
- **Désucrage `?`/`try`** : `?` propage `E` (au lieu de toujours `IronError`) ; `try/except e:` lie `e: E`.
- **Inférence de flux (I11)** : `E` déduit du `raise`/des `?` du corps quand non annoté ; défaut `IronError`
  (rétro-compat, D5).
- **Conversions** : un `?` sur un `Result[T, E1]` dans une fn `Result[T, E2]` exige `E1: Into<E2>` (filet rustc).

## Hors-périmètre
- `anyhow`/`thiserror`-style avancé → via import de crate (D1), pas dans le langage.

## Comportement attendu
```
enum DbError: NotFound, Timeout

def lookup(id: i64) -> Result[str, DbError]:
    if id < 0:
        raise DbError.NotFound
    return ok("row")
```
→ `fn lookup(id) -> Result<String, DbError>` ; `?`/`try` propagent `DbError`.

## Contrat / interface
`parse` : `Result[T, E]`. `ir.rs` : `Type::Result` à deux types (ou `ResultE(T, E)`). `infer/flow` : `E`
inféré/annoté. `lower` : `Result<T, E>`, `?` avec conversion `Into`.

## Source maps
I8 : les `?`/`raise` typés portent leur `Span` ; mismatch `E` → erreur rustc remontée (60800).

## Critères d'acceptation
- `Result[T, E]` avec `E` = enum Iron compile + `?`/`try` propagent `E` (test).
- Rétro-compat : `Result[T]` (sans `E`) = `Result[T, IronError]` comme avant.
- Mismatch `E` → erreur claire.

## Décomposition
→ planif `D2` : syntaxe `Result[T,E]`, IR, flux/inférence de `E`, désucrage `?`/`try`/`raise`, conversions.

## Risques / questions ouvertes
- 🔶 **Ampleur** (D5) : touche I11 + tout le désucrage erreur. `E` par défaut `IronError` limite la casse ;
  `E` explicite opt-in. À arbitrer.
