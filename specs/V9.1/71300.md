# [71300] LSP enrichi : complétion / hover / go-to-def + overlay rustc

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 71100, 60800, 60900, 21100 · Invariants : I8

## Objectif
Étendre le LSP minimal de V9 (71100, diagnostics seuls) à une **expérience éditeur complète** : complétion,
hover, go-to-définition, rename — **plus** l'overlay rustc (60800) pour des diagnostics profonds. C'est le
cerveau de l'intégration VSCode (chantier C).

## Périmètre
- **Diagnostics deux niveaux** (D4) : rapides (lex/parse/inférence locale, instantanés) + profonds (overlay
  rustc 60800, en arrière-plan, débattu).
- **Complétion** : après `obj.` → méthodes du type (struct/`impl`, ou type externe bindé via `Bindings`) ;
  après un préfixe → fns/variables en scope ; `import <…>` → crates connus.
- **Hover** : type inféré d'une expression (depuis la `TypeMap`) ; doc du symbole si dispo.
- **Go-to-def / rename** : fns/structs/variables (via `NodeId`/spans).
- État de document incrémental (cache AST par URI, recompile débattue).

## Hors-périmètre
- Refactorings avancés ; formatage à la frappe (→ `fmt` 71400).

## Comportement attendu
`r.` (où `r: Regex` bindé) → propose `is_match`/`find`/`captures` ; hover sur `r` → `Regex` ; go-to-def sur un
appel de fn user → sa définition.

## Contrat / interface
`lsp.rs` étendu : handlers `completion`/`hover`/`definition`/`rename` ; réutilise `infer`/spans/`Bindings`
(complétion crates) + l'overlay 60800 (diagnostics profonds, asynchrone).

## Source maps (I8)
La correspondance `Span` Iron ↔ position éditeur **est** la source-map ; la complétion des méthodes externes
exige le `.iri` chargé (cache 52100).

## Critères d'acceptation
- Complétion propose les méthodes d'un type bindé + les fns en scope (test scripté LSP).
- Hover montre le type inféré ; go-to-def saute à la définition.
- Diagnostics profonds (overlay rustc) apparaissent après les rapides (test deux-niveaux).

## Décomposition
→ planif `B3` : completion, hover, definition/rename, intégration overlay 60800, cache document, tests LSP.

## Risques / questions ouvertes
