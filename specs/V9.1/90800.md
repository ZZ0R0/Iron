# [90800] Gate V9.1 final

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : (toutes les specs V9.1) · Invariants : I1–I14

## Objectif
Le gate de clôture de V9.1 : prouver que **l'expérience développeur** tient ensemble — zéro lib Iron, support
langage par overlay rustc, intégration VSCode complète, profondeur (génériques/erreurs/closures), maturité
(paquets/doc/debug). Verdict honnête.

## Périmètre
- **Projet-vitrine** : multi-fichiers, **uniquement des `import` de crates Rust** (+ `import std`), génériques
  utilisateur, erreurs typées `Result[T, E]`, closures stockées, concurrence — compile (0 `unsafe`) + s'exécute.
- **Expérience VSCode** (prouvée par captures/tests d'intégration) : `.irn` reconnus + icônes, colorés,
  **diagnostics live** (rapides + overlay rustc), **complétion** des méthodes de crates importés, **quick-fix
  d'import**, **build/run au clic**, `ironc fmt` au save.
- **Outillage** : `ironc check/fmt/lint/doc/repl/lib/add` fonctionnent ; un **breakpoint** s'arrête sur une
  ligne Iron (72300).
- **Validation** : corpus + batterie-30 (90700) verts ; **métrique** (90100) ≥ V9 ; tous les `🔶` tranchés.

## Hors-périmètre

clic, formate, débogue — **sans aucune lib Iron**. Le gate agrège tout et prononce le verdict.
