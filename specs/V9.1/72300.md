# [72300] Intégration debugger (lignes Iron via source-maps)

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 60900, 71900 · Invariants : I8

## Objectif
Permettre de **déboguer en lignes Iron** (breakpoints, pas-à-pas) via gdb/lldb. Le binaire est du Rust compilé
(debug-info DWARF pointe les lignes `.rs`) ; il faut **relier les lignes `.rs` aux lignes `.irn`** (les
source-maps I8) pour que le debugger « parle Iron ».

## Périmètre
- **Mapping `.rs`↔`.irn`** : exposer les source-maps (60900) dans un format consommable par un adaptateur de
  debug (DAP) — ligne Rust → ligne Iron.
- **Adaptateur DAP minimal** (ou intégration VSCode) : un breakpoint posé sur une ligne `.irn` → traduit en
  ligne `.rs` → posé via lldb ; à l'arrêt, la position Rust → re-traduite en `.irn` (affichage).
- **Build debug** : `ironc build --debug` garde les infos (pas de strip) + la map.

## Hors-périmètre
- Inspection des variables en **noms Iron** (les locaux sont hoistés/renommés) → best-effort, post-v0.
- DWARF custom émis par Iron (on s'appuie sur celui de rustc).

## Comportement attendu
Breakpoint sur `main.irn:10` → l'exécution s'arrête, VSCode montre **`main.irn:10`** (pas le `.rs`).

## Contrat / interface
`sourcemap` : export ligne-à-ligne `.rs`↔`.irn`. Adaptateur DAP (ou config `launch.json` VSCode) consommant la
map + lldb. `ironc build --debug`.

## Source maps (I8)
**C'est l'application directe de I8** : le debugger EST le consommateur ultime des source-maps. Exige la
granularité au moins ligne (60900 pour l'expression, optionnel).

## Critères d'acceptation
- Un breakpoint sur une ligne `.irn` arrête l'exécution à la bonne position ; l'arrêt affiche la ligne `.irn`.
- Pas-à-pas avance en lignes Iron (approx. acceptable).

## Décomposition
→ planif `D7` : export map `.rs`↔`.irn`, adaptateur DAP/launch.json, build --debug, test breakpoint.

## Risques / questions ouvertes
- 🔶 Une ligne Iron → plusieurs lignes Rust (idiomes/hoisting) → choisir la 1ʳᵉ ; le pas-à-pas peut « sauter ».
  Documenter ; raffiner via 60900.
- 🔶 Variables : noms Rust hoistés ≠ noms Iron → inspection limitée au v0.
