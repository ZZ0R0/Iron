# [71600] Grammaire de coloration syntaxique (TextMate)

- Version : V9.1 · Milestone : M9.1 · Statut : draft · Dépend de : 71500 · Invariants : —

## Objectif
Colorer le code Iron dans VSCode (et tout éditeur TextMate) : mots-clés, types, chaînes, f-strings,
commentaires, décorateurs `@`, nombres. La coloration est **statique** (regex TextMate), indépendante du LSP —
elle marche même hors-ligne, instantanément.

## Périmètre
- **`iron.tmLanguage.json`** : règles pour :
  - mots-clés : `def`/`class`/`if`/`else`/`elif`/`for`/`while`/`return`/`import`/`use`/`match`/`try`/`except`/
    `raise`/`yield`/`async`/`await`/`lambda`/`extern`/`crate`/`assert`/`in`/`not`/`and`/`or`.
  - types : `i64`/`f64`/`bool`/`str`/`list`/`dict`/`set`/`Option`/`Result`/`tuple`/zoo numérique + PascalCase.
  - littéraux : nombres, chaînes `"…"`/`'…'`, **f-strings** `f"…{expr}…"` (interpolation colorée), `True`/`False`/`None`.
  - commentaires `#`, décorateurs `@derive(...)`, blocs `rust { … }` (Rust embedded si possible).
- Rattachée au langage `iron` (71500) via `contributes.grammars`.

## Hors-périmètre
- Coloration sémantique (couleurs selon le type inféré) → via LSP semantic tokens, post-v0.
