# [80100] Stdlib — prélude de built-ins

- Version : V4 · Milestone : M6 · Statut : implémenté · Dépend de : 40100 · Invariants : I5, I7

## Objectif
Prélude de fonctions built-in, **wrappers fins sur `std`** (I5 : pas de runtime lourd ; I7).

## Comportement (Iron → Rust)
`str(x)`→`(x).to_string()` · `abs(x)`→`(x).abs()` · `sqrt(x)`→`(x).sqrt()` · `min(a,b)`→`(a).min(b)` ·
`max(a,b)`→`(a).max(b)` · `concat(a,b)`→`format!("{}{}",a,b)` · `push(l,x)`→`l.push(x)` ·
`sum(l)`→`l.iter().sum::<i64>()`.

## Contrat / interface
Built-ins reconnus dans `call()` (lowering) + types de retour dans l'inférence. Littéraux numériques
**suffixés** (`i64`/`f64`) → appels de méthode sans ambiguïté.

## Critères d'acceptation
Programme `str/abs/min/max/sqrt/push/sum/concat` → `cargo` vert + sortie correcte. Corpus V0–V3 vert.

## Risques / questions ouvertes
- Built-ins = **noms réservés** (masquent un extern `.iri` homonyme). `sum` mono (`list[i64]`).
