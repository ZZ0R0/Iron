# [1.1] Fondation : boucle de point fixe + type `Promoted` + `gen` réentrant

- Spec parente : V10.1/R1 · Version : V10.1 · Dépend de : V10 · Statut : todo · **Vague 1**

## But
Poser la **structure** sans changer le comportement : une boucle de point fixe dans `mod.rs`, le type
`Promoted` (params promus en génériques), et une génération **re-exécutable**. Au sortir de 1.1, un seul tour
+ `Promoted` vide ⇒ comportement V10 ⇒ corpus vert. C'est le contrat figé pour la bascule (2.1) et les
raffinements (3.x).

## Fichiers touchés
`src/infer/engine/mod.rs` (boucle `resolve_params`) · **création** `src/infer/engine/promote.rs` (type
`Promoted = HashSet<u32>` + signatures stub `detect_conflicts`/`promote`) · `gen.rs`/`generalize.rs`
(signatures élargies pour recevoir `&Promoted`, **comportement inchangé**).

## Étapes
1. `promote.rs` : `pub type Promoted = HashSet<u32>;` + stubs `detect_conflicts(cs, subst) -> Vec<Conflict>`
   et `promote(...)` (vides en 1.1).
2. `Gen::program(ast, promoted: &Promoted)` : signature élargie ; en 1.1, ignore `promoted` (freshise comme
   V10). La génération doit pouvoir tourner **plusieurs fois** sur la même `Subst` (réentrance).
3. `mod.rs` : `resolve_params` devient la boucle `build_env → loop { gen → solve } → default → writeback`,
   **bornée à 1 tour** en 1.1, `Promoted` vide.

## Critère de done
`cargo build` vert ; **un tour, promotion vide** ⇒ corpus 50 + binding 30 VERTS (V10 préservé) ; `lower`
reçoit zéro `Var`. Le contrat (`Promoted`, `gen` réentrant, la boucle) est figé.
