# [30500] Ownership whole-program unifié — escape analysis interprocédurale à point fixe

- Version : V16
- Milestone : ownership-whole-program
- Statut : draft
- Dépend de : [30100] (clone/move), [30200] (escape analysis intra-proc), I15 (inférence whole-program — modèle)
- Invariants applicables : I1, I2, I3, I4, I15

## Objectif
Remplacer l'escape analysis **intra-procédurale + heuristique** de `resolve.rs` par une **analyse de flot
interprocédurale à point fixe**, jumelle de l'inférence de types (I15). Une **seule** analyse détermine, pour
chaque accès à une donnée non-`Copy` (argument, récepteur de méthode, **opérande d'opérateur**, variable de
boucle, capture), s'il s'agit d'une **lecture/emprunt**, d'un **move** (dernière utilisation prouvée) ou d'une
**consommation** (clone). But : **cloner seulement quand c'est réellement nécessaire** → lever le plafond de
perf et faire disparaître les frictions §2.1/§2.2/§2.6 du rapport.

## Périmètre
- **Modes de paramètres interprocéduraux** : `ParamMode` (`ByRef`/`ByValue`/`InOut`) calculé en **point fixe**
  sur le **graphe d'appels**, en consultant le mode du **callee** à chaque site (plus de whitelist `print`/`len`).
- **Analyse de dernière-utilisation réelle** (move vs clone) voyant la réutilisation **intra-expression**
  (remplace `compute_moves` single-use).
- **Variable de boucle `for`** : élément **emprunté** (`for x in &xs`) si le corps ne le consomme pas.
- **Opérateurs surchargés** : routés par la **même** analyse que les appels de méthode (un seul chemin).
- **Captures de closure/thread** : un paramètre capturé par valeur (move) → `ByValue` ; capturé en lecture → emprunt.

## Hors-périmètre
- **Borrow-checking complet** : `rustc` reste le filet (I2). V16 choisit emprunt/clone, il ne prouve pas
  l'absence d'aliasing mutable.
- **Durées de vie essentielles** : une référence **stockée** qui survit à l'appel reste **clone** (ou `rust{}`).
  Pas d'inférence de lifetimes (hors-périmètre du 0.1 %).
- **Partage mutable** : inchangé — `inout`/`shared` explicite (I3).

## Comportement attendu

### Le treillis (monotone, sûr)
Chaque `(fonction, paramètre)` non-`Copy` et non-`inout` :
```
ByRef (optimiste, sommet)  ⊒  ByValue (rétrogradé, fond)
```
- **Init** : tout param non-`Copy`/non-`inout` = `ByRef`.
- **Transition** : on ne fait que **rétrograder** `ByRef→ByValue`. Jamais l'inverse. → **monotone ⇒ terminaison**.

### Règles de rétrogradation (un param `p` devient `ByValue` ssi il s'échappe *vraiment*)
1. **Retourné** : `return p` (move entier) ou `return p.champ` (move-hors-struct, déjà 30400).
2. **Stocké** : affecté à un champ/élément de collection/variable qui **survit** à la fonction (struct-literal,
   `xs.append(p)`, capture `move`).
3. **Passé à une position consommante** : argument à la position `j` d'un callee `g` dont le param `j` est
   **actuellement `ByValue`** (← **le point interprocédural** : on consulte le mode courant du callee).
4. **Builtin consommant** (pas `print`/`len`/comparaisons/base de champ-index, qui empruntent).
5. **Incertitude** : tout cas non prouvé emprunt-seul → **`ByValue`** (sûr par sur-approximation).

> **Ne rétrograde PAS** : passé à une position `ByRef`, récepteur de méthode, base de `Field`/`Index`,
> opérande de comparaison, itérable de `for`, argument de `print`/`len`.

### Point fixe
Worklist sur le graphe d'appels : tant qu'un mode change, re-évaluer les fonctions appelantes/appelées
concernées. Converge (monotone). Gère la **récursion mutuelle** `ray_color`↔`shade`.

### Exemples `Iron → Rust généré`

**Récursion mutuelle lisant une scène (le cas du rapport) :**
```python
def ray_color(scene, r, depth):           # scene seulement LUE (scene.world.hit(...)), re-passée à shade/ray_color
    rec = scene.world.hit(r, 0.001, INF)
    return shade(rec.mat, scene, r, depth)
```
```rust
// AVANT (V15) : scene ByValue → clone par échantillon ET par rebond
pub fn ray_color(scene: Scene, r: Ray, depth: i64) -> Vec3 { … shade(rec.mat, scene, r, depth) }
// APRÈS (V16) : point fixe prouve scene/r seulement empruntés → &Scene/&Ray
pub fn ray_color(scene: &Scene, r: &Ray, depth: i64) -> Vec3 { … shade(&rec.mat, scene, r, depth) }
```
**Boucle read-only :**
```python
for obj in scene.world.objects:           # obj seulement lu (obj.hit(...))
    ...
```
```rust
// AVANT : .iter().cloned() (clone chaque élément)   →   APRÈS : &scene.world.objects (élément emprunté)
```
**Opérateur sur valeur empruntée (§2.1) :**
```python
c = a + b                                  # a, b : Vec3 empruntés (params/champs lus)
```
```rust
// AVANT : `a + b` → E0369 (cannot add Vec3 to &Vec3)   →   APRÈS : routé comme a.add(b) (autoref), compile
```
**Réutilisation intra-expression (§2.2) :**
```python
return v.sub(n.scale(2.0 * v.dot(n)))      # n réutilisé dans la même expression
```
```rust
// AVANT : `borrow of moved value: n` (single-use heuristic move trop tôt)
// APRÈS : last-use voit la 2ᵉ lecture → n emprunté (pas de `.copy()` manuel)
```

## Contrat / interface
- **Entrée** : l'AST + la `TypeMap` (résolue par l'inférence, qui tourne **avant** — nécessaire pour résoudre
  les appels de méthode `x.m()` → la méthode ciblée).
- **Sortie inchangée en TYPE** : `(OwnershipMap, ParamModes)` — mêmes structures qu'aujourd'hui, mais **calculées
  whole-program**. → **`lower.rs` n'a presque rien à changer** : la moitié *émission* marche déjà
  (`lower.rs:1875-1884` passe `&arg` quand le callee est `ByRef`).
- **Graphe d'appels** : construit depuis l'AST. Arêtes = appels de fn libres (callee = `Var(f)`), appels de
  méthode (résolus via `TypeMap` → `(type, méthode)`), opérateurs (désucrés en `__dunder__`). Modes des **fns
  externes** = lus des bindings (`ExternFn.recv`/`param_owned`).
- **Désucrage opérateurs** : `a OP b` → appel de méthode `a.__op__(b)` **avant** l'analyse, pour un **chemin
  unique** ownership (décision figée : désucrer, pas patcher le codegen opérateur séparément).
- **Décision figée — contrat de sûreté** : sur-approximation conservatrice (cf. README §Sûreté). Dans le doute,
  `ByValue`. Jamais de `ByRef` non prouvé sûr.

- **Terminaison** : le point fixe converge sur la récursion mutuelle (test `ray_color`↔`shade`).

## Risques / questions ouvertes
- **🔴 Rayon de souffle** : change la structure d'emprunts de **tout** le Rust généré → risque de régression
  corpus. Mitigation : invariant « corpus vert » à chaque étape ; sur-approximation conservatrice.
- **❓ Résolution des appels de méthode dans le graphe** : nécessite la `TypeMap` ; un récepteur de type non
  résolu → conservateur (`ByValue`). À spécifier en planif.
- **❓ Closures/threads** : la capture `move` doit forcer `ByValue` sur les captures — interaction avec le
  module `thread` minimal (lower.rs). Borné en planif.
- **🔶 §2.6 parallélisme** : en grande partie un **corollaire** (une fois l'ownership correct) ; l'ergonomie
  `thread.scope(&scene)` est un **plus**, hors fondation.
