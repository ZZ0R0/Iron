# [71000] `ironc fmt` : formateur Iron canonique

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 10100, 10200 · Invariants : I9

## Objectif
Donner à Iron son **formateur** (différé V7/70600). Un format canonique unique (indentation, espaces,
ordre) — pilier DX d'un langage fini (« il y a un fmt » = il est sérieux).

## Périmètre
- **`ironc fmt <fichier|dossier>`** : reformate en place (ou `--check` pour CI).
- Règles canoniques : indentation 4 espaces, 1 espace autour des opérateurs/`=`, pas d'espace avant `:`/`(`,
  lignes vides normalisées (1 entre fns, 0 en trop), longueur de ligne **non** imposée au v0.
- Réutilise le **lexer + parser** existants → ré-émet la source depuis l'AST (round-trip stable :
  `fmt(fmt(x)) == fmt(x)`).
- Préserve les **commentaires** (attachés aux nœuds).

## Hors-périmètre
- Réorganisation sémantique (tri des imports, etc.) au v0.
- Configuration fine (un seul style canonique, comme `gofmt`).

## Comportement attendu
`x=f( a,b )` → `x = f(a, b)`. Indentation/lignes vides normalisées. Idempotent.

## Contrat / interface
`fmt.rs` : `format(src) -> String` (AST → source canonique). CLI `ironc fmt [--check]`. Conserve les
commentaires (le lexer doit les exposer, sinon extension lexer).

## Source maps
N/A (transformation source→source, hors pipeline de codegen).

## Critères d'acceptation
- `fmt` idempotent sur tout le corpus (`fmt(fmt(x)) == fmt(x)`).
- `fmt` ne change **jamais** la sémantique (corpus reste vert après `fmt`).
- Commentaires préservés.

## Décomposition
→ planif : pretty-printer AST→source, préservation commentaires, CLI `--check`, test idempotence sur corpus.

## Risques / questions ouvertes
- 🔶 Préservation des commentaires = le point dur (le lexer les jette peut-être) → peut exiger une extension
  lexer (tokens trivia). Cadrer.
