# [51800] Inverse : export Iron → crate Rust (`ironc lib`)

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 40100, 70300 · Invariants : I2, I9, I10

## Objectif
Fermer la **réciproque** de l'interop : permettre à du **code Rust** de réutiliser un module Iron. C'est
quasi-trivial (Iron *est* du source Rust généré) ; il manque l'**emballage** : émettre un crate Rust
`{Cargo.toml, src/lib.rs}` exposant les items publics Iron, au lieu d'un binaire `main`.

## Périmètre
- **`ironc lib <module.irn>`** : compile le module Iron en `src/lib.rs` (items `pub`) + `Cargo.toml`.
- Items exportés : fonctions/structs/enums **publics** Iron → `pub fn`/`pub struct`/`pub enum` Rust.
- Signatures **propres** : les types Iron (projection I6) → types Rust publics ; pas d'`unsafe` (I2).
- Le crate généré se déclare dans le `Cargo.toml` d'un projet Rust hôte comme dépendance `path`.

## Hors-périmètre
- ABI binaire stable (Iron expose une API **source/crate**, pas un `.so` C — cohérent avec le modèle V8).
- Génériques Iron exposés à Rust (post-V9 si besoin).

## Comportement attendu
```
# math.irn
def add(a: i64, b: i64) -> i64:
    return a + b
```
`ironc lib math.irn` → `src/lib.rs` : `pub fn add(a: i64, b: i64) -> i64 { a + b }` + `Cargo.toml`.
Un projet Rust hôte : `use math::add;`.

## Contrat / interface
`driver` : sous-commande `lib` ; `emit_lib(out_dir, rust_src, crates)` (variante de `emit_project` produisant
`lib.rs`). Le lowering existant (40100) produit déjà les items ; on change l'**enveloppe** (lib vs main).

## Source maps
I8 préservée (le `lib.rs` porte les mêmes marqueurs que `main.rs`).

## Critères d'acceptation
- `ironc lib` sur un module à fns/structs publics → crate Rust qui **compile** et est **utilisable** depuis un
  projet Rust hôte (test : un `main.rs` Rust appelle une fn Iron exportée).
- 0 `unsafe` ; types publics propres.

## Décomposition
→ planif : sous-commande `lib`, `emit_lib`, sélection des items publics, test hôte Rust.

## Risques / questions ouvertes
- 🔶 Visibilité : tout `def` top-level → `pub` ? Ou marqueur `export` explicite ? **Proposé** : tout public au
  v0 (cohérent avec la simplicité Iron) ; marqueur affinable.
