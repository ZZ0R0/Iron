# [2.1] Binding des méthodes de traits + protocoles bénis

- Spec parente : 51600 · Version : V9 · Dépend de : 1.1 · Statut : todo · **Vague 2** (séquentiel-incrémental)

## But
Binder les `impl Trait for T` et mapper les traits std bénis vers les protocoles Iron (`for`/`str`/opérateurs/`[]`).

## Fichiers touchés
`src/bind.rs` (extraction `impl Trait`, table protocoles) · `src/infer/*` + `src/lower.rs` (résolution par protocole).

## Étapes
1. bind : parcourir les `impl Trait for T` (non blanket/synthétiques), extraire méthodes ; tag `[proto:...]`.
2. Table traits bénis → protocole Iron (Iterator→for, Display→str, Add→+, Index→[], …).
3. infer/lower : un protocole béni sur `Extern` se résout comme l'opérateur/`for`/`str` Iron.

## Critère de done
sha2/chrono/`find_iter` utilisables **sans `rust{}`** (demos V8 réécrites) ; `for x in <iter externe>` compile ;
gate binding VERT.
