# [4.1] `shared_sync[T]` → `Arc<Mutex>`

- Spec parente : 30700 · Version : V9 · Dépend de : 1.1 · Statut : todo · **Vague 4** (séquentiel)

## But
Partage mutable thread-safe : `shared_sync[T]` → `Arc<Mutex<T>>`, `ref_sync(x)`, accès `with`/`lock`.

## Fichiers touchés
`src/infer/*` (`ref_sync`→SharedSync, `with`) · `src/lower.rs` (`Arc<Mutex>`, `.lock().unwrap()`, `Arc::clone`)
· `src/resolve.rs` (partage explicite I3).

## Étapes
1. infer : `ref_sync`→`Type::SharedSync` (gelé 1.1) ; `with s as c:` lie le contenu verrouillé.
2. lower : `Arc::new(Mutex::new(x))`, accès `.lock().unwrap()`, clone `Arc::clone`.
3. resolve : `shared_sync` = partage explicite (jamais auto-cloné, I3).

## Critère de done
`ref_sync` + `with` compile, `Arc<Mutex>` émis, 0 `unsafe` ; clone = `Arc::clone` ; passage à un thread (4.2)
compile là où `shared` échoue (test comparatif).

## Notes
Deadlock (double lock) = footgun runtime (comme double-borrow RefCell) ; `with` scoped limite. Documenter.
