# [2.3] Inverse : export Iron → crate Rust (`ironc lib`)

- Spec parente : 51800 · Version : V9 · Dépend de : 1.1 · Statut : todo · **Vague 2** (parallélisable — driver/CLI)

## But
`ironc lib <module.irn>` émet un crate Rust `{Cargo.toml, src/lib.rs}` réutilisable depuis du Rust.

## Fichiers touchés
`src/driver.rs` (`emit_lib`, sous-commande `lib`) · `src/main.rs` (CLI).

## Étapes
1. `emit_lib(out_dir, rust_src, crates)` : variante de `emit_project` produisant `lib.rs` (pas de `main`).
2. Items publics Iron → `pub fn/struct/enum` (le lowering 40100 les produit déjà ; changer l'enveloppe).
3. CLI `ironc lib`.

## Critère de done
`ironc lib` sur un module à fns/structs → crate Rust qui compile ; un `main.rs` Rust hôte appelle une fn Iron exportée (test). 0 `unsafe`.

## Notes
Ownership disjoint (driver/CLI) → parallélisable. Visibilité : tout top-level `pub` au v0.
