# [3.4] Générateurs `yield` → itérateurs

- Spec parente : 10900 · Version : V9 · Dépend de : 1.1 · Statut : todo · **Vague 3** (séquentiel — frontend/lower)

## But
`yield` dans une boucle simple → `impl Iterator` (chaîne d'itérateurs) ; `for x in gen()` consomme.

## Fichiers touchés
`src/lex.rs` + `src/parse.rs` (`yield`) · `src/infer/*` (fn à yield → `iter[T]`) · `src/lower.rs` (motif→chaîne).

## Étapes
1. Lexer/parser `yield` (déjà réservé en 1.1) → `StmtKind::Yield`.
2. infer : fn à `yield` → `iter[T]` (≈ `impl Iterator`).
3. lower : reconnaître `for … : (if …) yield e` → `(iter).filter(...).map(...)` ; sinon **erreur claire**.

## Critère de done
Générateur « boucle+condition+yield » → itérateur correct consommé par `for` ; cas hors-périmètre → erreur
claire orientant vers `rust{}` (pas de codegen faux).

## Notes
**Le plus risqué (D5).** Frontière simple/complexe doit être **prévisible** — documenter les motifs supportés.
