# [51700] Robustesse du bind : ré-exports, collisions, getters, itérateurs

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 51000, 51100, 51200, 51300 · Invariants : I6, I7

## Objectif
Éliminer les **bords rugueux** de l'auto-bind trouvés en V8 (cf. `specs/V8/realisation.md`) pour que
`ironc bind <crate>` produise un `.iri` **directement utilisable** sur le cas courant, sans curation.

## Périmètre
- **Résolution des chemins de ré-export publics** : aujourd'hui rustdoc donne le chemin **interne**
  (`regex::regex::string::Regex`) ; tracer la chaîne de ré-export pour émettre le chemin **public**
  (`regex::Regex`). À défaut, heuristique `<crate>::<Type>` (déjà là) + détection de collision.
- **Collisions de noms courts** : `regex::Regex` (str) vs `regex::bytes::Regex` (bytes) → ne **pas** fusionner ;
  désambiguïser par sous-module (suffixe `bytes`), garder le ré-export racine comme nom canonique.
- **Getter `&str` → `.to_string()`** : la glue `[clone]` doit produire `.to_string()` pour un retour `&str`,
  `.clone()` pour `&T`, `.cloned()` pour `Option<&T>` (V8 émettait `.clone()` partout — faux pour `&str`).
- **Itérateur d'`Item` non-scalaire** : `[collect]` sur `Item = &Match` → map vers le tuple/handle projeté.
- **Profondeur de modules** : grouper correctement les items en sous-modules (`crate::a::b::fn`).

## Hors-périmètre
- Les traits (51600), l'instance-pinning (51400).

## Comportement attendu
- `ironc bind regex` → un seul `Regex` (str), `BytesRegex` (bytes) distinct, chemins publics corrects.
- Un getter `as_str(&self) -> &str` → `fn as_str(self) -> str = "as_str" [clone]` → lower émet `.to_string()`.

## Contrat / interface
`bind.rs` : passe de résolution de ré-exports (parcours des items `import`/`use` du rustdoc) ; table
nom-court → chemin-public ; désambiguïsation des collisions. `lower` : glue `[clone]` typée (`&str` vs `&T`).

## Critères d'acceptation
- L'`.iri` **auto** de regex/serde_json/csv est **utilisable sans curation** sur ≥ 1 programme chacun.
- Pas de collision str/bytes ; getters `&str` rendent une `str` possédée correcte (test).
- Mesure : part des items bindés **utilisables directement** (compile à l'usage) ≥ 90% des items bindés.
