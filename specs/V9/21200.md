# [21200] `async`/`await` → Rust async + runtime bindé

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 20200, 40100, 70700 · Invariants : I2, I9, I11

## Objectif
Donner l'**asynchrone** à Iron — le **chantier le plus lourd de V9**. `async def`/`await` mappés vers le
`async`/`.await` de Rust, avec un **runtime** fourni par un crate bindé (tokio par défaut). Débloque le vrai
HTTP async (reqwest), l'I/O concurrente, etc.

## Périmètre
- **Syntaxe** : `async def f(...)` → `async fn`, `await expr` → `expr.await`. `AST` : marqueur `async` sur fn,
  `ExprKind::Await`.
- **Inférence** : `async def` retourne un `Future` ; `await` déplie le `Future` (pendant async de `?`, I11).
- **Runtime** : `#[tokio::main]` injecté sur `main` si le programme est async (D4) ; runtime choisi via
  `ironc.toml` (`[iron] async_runtime = "tokio"`).
- **Lowering** : `async`/`.await` émis tels quels (TokenStream, I10) ; le runtime vient du crate bindé.

## Hors-périmètre
- `select!`, pinning manuel, streams complexes → `rust{}` (0.1%, D6).
- Annulation/timeouts fins (post-V9 ou via binding).

## Comportement attendu
```
import reqwest
async def fetch(url: str) -> Result[str]:
    resp = await reqwest.get(url)
    return ok(await resp.text())
```
→ `async fn fetch(url: String) -> Result<String, IronError> { let resp = reqwest::get(url).await…; … resp.text().await… }`
+ `#[tokio::main] async fn main()`.

## Contrat / interface
`lex`/`parse` : `async`/`await`. `ir.rs` : `Item::Fn.is_async`, `ExprKind::Await`. `infer` : Future-flow.
`lower` : `async fn`/`.await`, injection runtime. `ironc.toml` : runtime.

## Source maps
I8 : `await` porte le `Span` ; une erreur async `rustc` (Send/Sync de Future) remonte au `Span` Iron.

## Critères d'acceptation
- Un programme `async def`/`await` (HTTP async via reqwest bindé) compile + s'exécute + sortie juste.
- `main` async → runtime tokio injecté ; 0 `unsafe`.
- `await` déplie `Future`/`Result` (flux I11).

## Décomposition
→ planif : lexer/parser `async`/`await`, IR, inférence Future, lowering + runtime, demo HTTP async.

## Risques / questions ouvertes
- 🔶 **Le plus risqué de V9.** Bornes `Send`/`Sync`/`'static` des Futures → erreurs `rustc` parfois opaques ;
  remontée I8 + messages à soigner.
- 🔶 Runtime imposé (tokio) vs choisi → D4 à arbitrer. Coût de compilation (tokio est lourd).
- 🔶 Interaction async × threading (30700/70900) → documenter les combinaisons supportées.
