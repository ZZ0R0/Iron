# [60700] Source-maps granularité expression

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 60100, 40100 · Invariants : I8, I10

## Objectif
Affiner les **source-maps** à la granularité **expression** (différé V6/60200) : aujourd'hui la remontée est
surtout par **ligne** ; pour un LSP et des diagnostics précis, il faut mapper chaque **expression** Rust
générée à son `Span` Iron exact. C'est le « mécanisme marqueur invisible » resté ouvert.

## Périmètre
- **Mécanisme** : émettre un marqueur invisible (`__irn_mark!(idx)`) **par expression significative** (pas
  seulement par stmt), encodant l'index du `SpanLink` ; la remontée d'une erreur `rustc` résout au `Span`
  Iron le plus fin.
- **Granularité** : appels, opérateurs, accès de champ/index, méthodes externes — chacun mappé.
- Ne pas alourdir le Rust généré au point de changer la sémantique (les marqueurs sont des no-op, I10).

## Hors-périmètre
- Debug-info DWARF (on reste sur la remontée textuelle `rustc` → Iron).

## Comportement attendu
Une erreur `rustc` sur la sous-expression `r.is_match(x)` d'une ligne complexe → pointe **`r.is_match(x)`**,
pas toute la ligne.

## Contrat / interface
`sourcemap` + `lower` : `SpanLink` par expression ; marqueur émis en position d'expression (pas seulement
stmt). `remontee` (driver) résout au lien le plus fin couvrant la position Rust.

## Source maps (I8)
**C'est le cœur de la spec** : raffiner le mapping `Span` Iron ↔ Rust de la ligne vers l'expression.
Toute spec de codegen V9 (40200/40300/40400) en bénéficie.

## Critères d'acceptation
- Une erreur introduite dans une sous-expression → remontée pointe l'**expression**, pas la ligne (test).
- Pas de régression sémantique (marqueurs = no-op) ; corpus vert.
- Le LSP (71100) consomme cette granularité pour positionner les diagnostics.

## Décomposition
→ planif : marqueurs par expression, résolution fine dans `remontee`, tests de précision.

## Risques / questions ouvertes
- 🔶 Volume de marqueurs (un par expression) → coût de compilation/lisibilité du Rust généré ; borner aux
  expressions « intéressantes » (appels/opérateurs), pas les littéraux.
