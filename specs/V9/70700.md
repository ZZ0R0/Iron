# [70700] `import <crate>` : auto-bind caché + cache

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 50300, 50900, 70200, 70300 · Invariants : I7

## Objectif
Rendre l'import d'un crate **ergonomique** : `import regex` en **une ligne**, au lieu du 2-temps V8
(`ironc bind regex > regex.iri` puis `use "regex.iri"`). C'est le passage de « ça marche » à « c'est
agréable » — prérequis du « langage fini ».

## Périmètre
- **Syntaxe** : `import <crate>` (réutilise le mot-clé `import` des modules Iron 70200 ; le driver distingue
  module-Iron-local vs crate-Rust via `ironc.toml`/présence du `.irn`).
- **Résolution de version** : via `ironc.toml` (`[dependencies] regex = "1"`, D4/70300).
- **Auto-bind caché** : si pas de `.iri` curé, lancer `ironc bind` automatiquement, **mettre en cache** le
  `.iri` (clé = crate+version) sous `target/iron-bindings/` ; ne re-binder que si la version change.
- **Désucrage** : `import regex` → charge le `.iri` (curé du registre 70800 sinon auto) + injecte la dépendance.

## Hors-périmètre
- Le registre curé lui-même (70800). Le binding (50300/50900).

## Comportement attendu
```
import regex                 # 1 ligne ; résout version via ironc.toml, bind+cache si besoin
def main():
    r = Regex.new("[0-9]+")
    ...
```

## Contrat / interface
`driver` : `import <name>` → cherche (1) `name.irn` (module Iron), (2) `.iri` curé (registre), (3) auto-bind
caché. Cache `target/iron-bindings/<crate>-<version>.iri`. `ironc.toml` fournit la version.

## Critères d'acceptation
- `import regex` (avec `regex` dans `ironc.toml`) → programme compile+s'exécute, **sans** `bind`/`use` manuels.
- 2ᵉ compilation : pas de re-bind (cache hit) ; changement de version → re-bind.
- Cohabitation : `import mymod` (module Iron local) marche toujours (70200).

## Risques / questions ouvertes
- 🔶 Latence du 1ᵉʳ `import` (rustdoc-json est lent) → message « binding de regex… » + cache agressif.
- 🔶 Crate absent d'`ironc.toml` → erreur claire « ajoute `regex` à [dependencies] ou `ironc add regex` ».
