# [60500] Passe de lint réelle (I4)

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 30100, 30200, 20100 · Invariants : I3, I4

## Objectif
Une **vraie passe de lint** (différée V7/60300) au-delà du simple comptage de clones `--audit` : variables
inutilisées, **clones évitables**, code mort, shadowing, aliasing suspect (I3). Chaque lint porte un `Span`
Iron + un code `IRN-Lxxx`.

## Périmètre
- **Lints** : variable assignée jamais lue ; **clone-fallback évitable** (un emprunt aurait suffi, I4) ;
  branche/fonction mortes ; shadowing implicite ; partage mutable sans `inout`/`ref` (I3, « tu voulais
  peut-être partager »).
- **Sévérité** : `warn` par défaut (off sauf `--audit`), `deny` opt-in ; jamais bloquant sauf `deny` (I4).
- **Codes** : `IRN-L001` (unused), `IRN-L002` (clone évitable), `IRN-L003` (dead code), … (table).

## Hors-périmètre
- Lints stylistiques (→ `fmt` 71000). Lints de perf fins au-delà du clone (post-V9).

## Comportement attendu
```
x = compute()        # IRN-L001: variable `x` inutilisée
y = big.clone()      # IRN-L002: clone évitable (emprunt suffirait)  [--audit]
```

## Contrat / interface
`lint.rs` : passe sur l'AST + `OwnershipMap` + `TypeMap` → `Vec<Lint { span, code, severity, msg }>`.
CLI : `ironc lint` (ou intégré à `--audit`). Étend l'audit clone existant (I4).

## Source maps
N/A direct (le lint travaille sur l'IR Iron) ; chaque lint **porte un `Span` Iron** (I8-compatible).

## Critères d'acceptation
- Détecte unused / clone-évitable / dead-code sur des cas-tests dédiés (positifs + négatifs).
- `warn` off par défaut, visible sous `--audit` ; `deny` fait échouer (opt-in).
- Aucun faux positif sur le corpus (lints justes).

## Décomposition
→ planif : passes (unused, clone-évitable, dead-code, shadowing, aliasing), codes/sévérité, CLI, tests.

## Risques / questions ouvertes
- 🔶 « Clone évitable » exige une analyse d'emprunt fiable (lien escape analysis 30200) → conservateur
  (ne signaler que les cas sûrs) pour éviter les faux positifs.
