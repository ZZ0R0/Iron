# [51600] Binding des méthodes de traits + protocoles bénis

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 50900, 51100, 51300 · Invariants : I6, I7

## Objectif
**Le levier central de V9.** V8 ne binde que les `impl` **inhérents** → les crates dont l'API idiomatique
passe par des **traits** (sha2/`Digest`, chrono/`Datelike`, itérateurs/`Iterator`, affichage/`Display`)
tombent en `rust{}`. Cette spec binde les **méthodes de traits** et mappe les **traits std « bénis »** vers
les protocoles Iron natifs — faisant basculer la moitié « hybride » mesurée en **Iron pur**.

## Périmètre
- **Méthodes de traits** : parcourir les `impl Trait for Type` (non blanket, non synthétiques) ; binder
  leurs méthodes comme méthodes du type (UFCS `Trait::method(&obj, …)` ou syntaxe-méthode).
- **Protocoles bénis** (mapping figé, D1) :
  - `Iterator`/`IntoIterator` → `for x in obj` (consomme via `.into_iter()`), et collecte `list[T]`.
  - `Display`/`ToString` → `str(obj)` → `format!("{}", obj)`.
  - `Add/Sub/Mul/Div/Rem` → `+ - * / %` sur le type externe.
  - `PartialEq`/`PartialOrd` → `== != < <= > >=`.
  - `Index` → `obj[i]`. `Default` → constructeur par défaut. `From`/`Into` → conversions.
  - `Clone` → la sémantique-valeur d'Iron (déjà acquise).
- **Traits user monomorphisables** : bindés par méthode si la signature se projette (51000) ; sinon sautés
  (→ `rust{}`, 0.1%).

## Hors-périmètre
- Traits génériques à bornes non résolues (→ instance-pinning 51400 ou `rust{}`).
- `async`-traits → 21200.

## Comportement attendu
```
# sha2 en Iron PUR (via le trait Digest bindé) :
h = Sha256()                       # Default / new
h.update("hello")                  # méthode de trait
digest = h.finalize()              # → bytes possédés
# chrono : d.weekday() (Datelike) en Iron pur
# itérateur : for m in re.find_iter(text):  (Iterator → for)
```

## Contrat / interface
`bind` : étendre l'extraction (51100) aux `impl Trait for T` ; table des traits bénis → protocole Iron.
`infer`/`lower` : un protocole béni sur un `Type::Extern` se résout comme l'opérateur/`for`/`str` Iron
correspondant. `.iri` v2 : tag optionnel `[proto:<nom>]` pour expliciter un protocole.

## Source maps
I8 préservée : chaque appel de méthode de trait / opérateur protocolaire porte le `Span` de l'expression Iron.

## Critères d'acceptation
- sha2, chrono, un itérateur de regex (`find_iter`) utilisables **sans `rust{}`** (réécriture des demos V8).
- `for x in <itérateur externe>` compile et itère.
- `str(obj)` sur un type `Display` → sortie correcte.
- Couverture auto **Iron-pur** des 10 crates de la batterie V8 ≥ 85% (mesurée).

## Décomposition
→ planif : extraction `impl Trait`, table protocoles bénis, résolution infer/lower par protocole, tests.

## Risques / questions ouvertes
- 🔶 Conflits de protocoles (un type impl plusieurs traits avec opérateurs) → priorité documentée.
- 🔶 `Iterator` à `Item` emprunté (`&T`) → collecter en possédé (clone, I4) ou itérer par valeur ; choisir.
