# [90400] Batterie « 30 vrais crates » (texte / web / données / concurrence)

- Version : V9 · Milestone : M9 · Statut : draft · Dépend de : 51600, 70700, 70900, 30700 · Invariants : I2, I7

## Objectif
Étendre la batterie des 30 projets V7 (arithmétique/algo) avec une suite de **vrais programmes utilisant de
vraies libs** — texte, web, données, concurrence — en **Iron pur** autant que possible (grâce à 51600).
C'est la preuve « langage utilisable pour de vrai » demandée.

## Périmètre
- **~30 projets** répartis : **texte** (regex : extraction/validation/tokenisation), **données** (serde_json :
  parse/transforme/agrège ; csv), **web** (ureq/reqwest : GET/parse de réponse ; async via 21200), **crypto/
  hash** (sha2), **temps** (chrono), **concurrence** (`thread`/`shared_sync` : map-reduce parallèle),
  **collections** (HashMap/BTree via binding), **CLI** (clap, optionnel).
- Chaque projet : multi-fichiers, ≥ 1 crate réel, sortie **déterministe/comparable** (entiers/chaînes
  explicites — règles de sortie du corpus V7).
- **Mode visé Iron-pur** ; `rust{}` autorisé pour le résidu 0.1%, **compté** (métrique 90100).

## Hors-périmètre
- Crates exotiques/async-lourds non garantis (notés, pas exigés).

## Comportement attendu
Ex. : « valide des emails » (regex), « agrège un JSON de logs » (serde_json), « somme parallèle 1..N en 4
threads » (`thread`+`shared_sync`), « GET + compte les liens » (ureq), « hash d'un fichier » (sha2).

## Contrat / interface
`tests/binding/` (et/ou `tests/projects-real/`) : 30 dossiers `{*.irn, *.iri/import, expected}` + runner
(extension de `tests/binding/run.sh`). Chaque projet a un oracle déterministe.

## Source maps
N/A (tests) ; les projets exercent la remontée I8 sur du code réel.

## Critères d'acceptation
- **30/30 compile + s'exécute + sortie = oracle**, 0 `unsafe`.
- Part **Iron-pur** (sans `rust{}`) **mesurée et reportée** (cible : majorité ; le reste documenté).
- Intégré au gate V9 (90500).
