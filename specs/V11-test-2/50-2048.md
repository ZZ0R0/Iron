# 50 — Jeu 2048 (en terminal)
> **Domaine** Jeux · **Crate(s)** `ironc add crossterm` · **Risque Iron** 🟢 · **Difficulté** modérée

## But
Un 2048 jouable au terminal : grille 4×4, une flèche par coup glisse et fusionne les tuiles, une nouvelle tuile apparaît à chaque mouvement, score, victoire à 2048 et fin de partie quand plus aucun coup n'est possible.

## Ce que ça teste dans Iron
- **Le meilleur ajustement de la série.** Jeu **au tour par tour**, sans temps réel, état minuscule (16 entiers) : `event::read()` bloquant pour **une touche par coup**, puis on redessine. Aucune boucle d'événements temps réel.
- Le **glisser-fusionner** d'une ligne est une **fonction pure** `[int;4] → [int;4]` — cadeau pour la sémantique par valeur : les quatre directions se ramènent à transposer/inverser puis appliquer cette fonction.
- `rand` (ou std) pour placer une tuile 2/4 ; pas d'état mutable partagé.
- Réutiliser **une seule** fonction de compactage de ligne pour les quatre directions (via transposition + miroir) : composition de transformations pures sur des tableaux fixes.

## Approche
`ironc add crossterm`. Boucle simple : afficher la grille, lire une flèche, appliquer le glisser-fusion dans la bonne direction (réutiliser la fonction de ligne via transposition/miroir), poser une nouvelle tuile si le plateau a changé, tester victoire/blocage. On peut rester minimal côté terminal (voire en mode ligne, sans raw-mode). Comparer le plateau avant/après pour décider s'il faut faire apparaître une tuile (un coup sans effet ne doit rien faire naître).

## Risque / limites attendues
- Risque faible : c'est de la **transformation de grille par valeur** + une touche lue + un affichage. Idéal pour Iron.
- Même réserve que les autres crossterm : `execute!`/`queue!` sont des macros → préférer les **méthodes de trait** ; mais on peut limiter crossterm au strict minimum.
- Aucune contrainte temps réel ni état partagé → pas de mur.
- `rand` pour la tuile (90 % de 2, 10 % de 4) est le seul effet non déterministe ; tout le reste est pur et trivial à tester.

## Done
Plateau 4×4 fonctionnel : les flèches glissent et fusionnent correctement, une tuile apparaît à chaque coup valide, le score se met à jour, victoire à 2048 et game over quand le plateau est bloqué.
