# [3.1] Surface : fn imbriquées · while/for-else · affectation chaînée · const globale

- Spec parente : 11100 · Version : V11 · Dépend de : 1.1 · Statut : todo · **Vague 3**

## But
Quatre constructions de surface, toutes par **désucrage** (zéro nouveauté runtime).

## Fichiers touchés
`src/parse.rs` (def imbriqué, `else` après while/for, assign chaînée, `const` top-level) · `src/lower.rs`
(closure / drapeau `__broke` / `__t` / `const`).

## Étapes
1. **fn imbriquée** : `def inner` dans un `block` → closure `let inner = |args| { corps }` (capture valeur).
   Inner récursive détectée → message clair.
2. **while/for-else** : `else:` après la boucle → `__broke` initialisé faux, `break` le met vrai ; `if
   !__broke { <else> }`.
3. **affectation chaînée** `a = b = expr` → `__t = expr; a = __t; b = __t`.
4. **const globale** : `NAME = <littéral>` au top-level → item `const`/`static` Rust (immuable).

## Critère de done
Fixtures : inner capturant une externe ; for-else trouvé/non-trouvé ; `a=b=expr` ; `MAX = 100` lisible →
compile+run+oracle. Corpus + binding VERTS.

## Notes
Séquentiel. État global **mutable** = hors-périmètre (I2) → erreur claire si tenté.
