# [2.1] Patterns : or-patterns + range patterns

- Spec parente : 11000 · Version : V11 · Dépend de : 1.1 · Statut : todo · **Vague 2**

## But
`1 | 2 | 3` (or-patterns) et `0..10` / `0..=10` (range patterns) dans `match`, désucrés vers Rust.

## Fichiers touchés
`src/lex.rs` (`|` toléré en contexte motif) · `src/parse.rs` (parsing motifs `|`/`..`/`..=`) · `src/lower.rs`
(bras `p1 | p2`, `lo..hi`/`lo..=hi`).

## Étapes
1. Parser : dans un motif de `match`, accumuler les alternatives `|` → `Pattern::Or` ; `lo..hi`/`lo..=hi` →
   `Pattern::Range`.
2. Lowering : `Pattern::Or` → `p1 | p2 | …` ; `Pattern::Range` → `lo..hi` / `lo..=hi`.
3. Bindings incohérents dans un or-pattern → erreur claire (avant rustc si possible, sinon filet).

## Critère de done
Fixtures : `1|2|3`, `4..10`, `10..=20` compilent + matchent juste ; or-pattern binding incohérent → erreur ;
non-régression `match` (littéraux/variantes/gardes/imbriqués). Corpus + binding VERTS.
