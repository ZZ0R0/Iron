# [6.3] Diagnostics de type Iron riches

- Spec parente : 23100 · Version : V11 · Dépend de : 6.1 · Statut : todo · **Vague 6** (∥ 6.2)

## But
Étendre les diagnostics natifs (D8) : champ/méthode inconnu, arité, borne de trait non satisfaite — sur la
ligne Iron, avant `rustc`. Le checker VSCode (`ironc check`) en bénéficie directement.

## Fichiers touchés
`infer/engine/diag.rs` (**possédé**) · `infer/engine/mod.rs` (`check_types` : nouvelles catégories). Disjoint
de 6.2 (gen.rs) → parallélisable.

## Étapes
1. **Champ inconnu** : `p.foo` où `p` résolu concret (struct) sans champ `foo` → message.
2. **Méthode inconnue** sur un type connu (struct/enum/externe).
3. **Arité d'appel** : args ≠ params d'une fonction connue.
4. **Borne de trait** non satisfaite quand le moteur peut la trancher.

## Critère de done
≥ 1 fixture négative par catégorie → message Iron natif sur le bon span ; **zéro faux-positif** (corpus 50 +
binding 30 + zero-annot VERTS).

## Notes
Parallèle à 6.2 (diag.rs disjoint). **Règle stricte** : ne signaler que sur un type **résolu concret** (sinon
faux-positif). Tout doute → `rustc` filet.
