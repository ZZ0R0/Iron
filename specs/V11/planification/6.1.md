# [6.1] Inférence : construction d'enum typée + scrutateur + anti-unification

- Spec parente : 23000 · Version : V11 · Dépend de : 1.1 · Statut : todo · **Vague 6**

## But
Combler les cas non couverts du moteur : typer `Enum.Variant(...)`, faire informer le scrutateur de `match`,
et généraliser par anti-unification (V10.1/D-e).

## Fichiers touchés
`infer/engine/gen.rs` (enum-construction + scrutateur) · `infer/engine/promote.rs` (anti-unification).

## Étapes
1. `gen.call` : si le callee est `Field(Enum, Variant)` avec `Enum` un enum connu → type `Enum`, unifier les
   args aux types de champs de la variante.
2. `match s: Enum.X(...)` → `Eq(typeof(s), Enum)` (le motif informe le scrutateur).
3. `promote` : anti-unification (LGG) — `list[i64]` vs `list[str]` → `list[T]` (généraliser à la position de
   divergence), pas le param entier.

## Critère de done
`def area(s): match s: Shape.Circle(r): …` appelé `area(Shape.Circle(2))` → compile **sans annotation** ;
`count` appelé en `list[i64]` ET `list[str]` → `count[T](list[T])` ; corpus + binding + zero-annot VERTS.
