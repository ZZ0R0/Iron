# [4.1] Traits user : `class(Trait)` + bornes + méthodes par défaut

- Spec parente : 23400 · Version : V11 · Dépend de : 1.1 · Statut : todo · **Vague 4**

## But
Rendre les traits utilisateur pleinement utilisables : implémentation par une classe, bornes génériques,
méthodes par défaut.

## Fichiers touchés
`src/parse.rs` (`class Name(Base, …):`, `trait` avec corps de méthode) · `src/ir.rs` (traits implémentés) ·
`src/lower.rs` (`impl Trait for Type`, trait avec défauts) · `infer/engine/assume.rs`+`gen.rs` (env trait).

## Étapes
1. **Parse** : bases de classe `class Dog(Show, Ord):` → liste de traits ; `trait T: def m(self): <corps>`
   (corps optionnel).
2. **Désucrage** : classe implémentant `Show` → `impl Show for Dog` (méthodes matchant le trait) ; trait avec
   défaut → méthode par défaut dans le trait Rust.
3. **Inférence** : `(trait, méthode) → signature` dans l'env ; `def f[T: Show]` → borne connue ; `x.show()`
   sur `T: Show` typé. Base inconnue comme trait → erreur claire.

## Critère de done
`class Dog(Show)` + `def display[T: Show](x): return x.shout()` + méthode par défaut → compile+run (« Rex ») ;
méthode de trait manquante → erreur ; non-régression class/trait/impl existants. Corpus + binding VERTS.

## Notes
Séquentiel, central (parse+ir+lower+infer). Pré-requis de 5.1 (dunders). `dyn Trait` hors-périmètre.
