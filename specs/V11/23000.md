# [23000] Inférence : construction d'enum typée + scrutateur informé + anti-unification

- Version : V11 · Milestone : M11 · Statut : draft · Dépend de : 21800, 22100 · Invariants : I15

## Objectif
Combler les cas non couverts du moteur (chantier A) : typer la **construction de variante d'enum**, laisser
le **`match` informer le type du scrutateur**, et généraliser par **anti-unification** (V10.1/D-e).

## Périmètre
- **DA-1** : `Enum.Variant(args)` (un `Call` dont le callee est `Field(Enum, Variant)`) → typé `Enum`
  (et args unifiés aux types des champs de la variante). Corrige `def area(s): match s: Shape.Circle(r): …`
  appelé `area(Shape.Circle(2))` **sans annotation**. En complément : un bras `match s: Enum.X(...)` émet
  `Eq(typeof(s), Enum)` (le motif **informe** le scrutateur).
- **DA-2 (anti-unification)** : à la promotion (V10.1), deux types **structurellement semblables** différant à
  une position (`list[i64]`/`list[str]`) → généraliser **à la position** (`list[T]`) plutôt que le param
  entier. Conflit à plat (`i64`/`str`) → promotion param-entier (déjà). Annoté → erreur.

## Hors-périmètre
- Diagnostics (23100), flux (23200).

## Comportement attendu
```
enum Shape: Circle(i64) ; Rect(i64, i64)
def area(s):                       # ZÉRO annotation
    match s:
        Shape.Circle(r): return r * r * 3
        Shape.Rect(w, h): return w * h
area(Shape.Circle(2))              # s = Shape, inféré
```

## Contrat / interface
`infer/engine/gen.rs` : reconnaître `Field(Enum, Variant)` en position d'appel → type `Enum` + unif des args
aux champs de la variante ; `match` → contrainte sur le scrutateur. `infer/engine/promote.rs` : anti-
unification (LGG) à la position de divergence.

## Critères d'acceptation
- `area(s)` (enum match) compile **sans annotation** ; `count` appelé en `list[i64]` ET `list[str]` →
  `count[T](list[T])` (anti-unif) ; corpus+binding+zero-annot verts.

## Décomposition
→ planif : (1) enum-construction + scrutateur ; (2) anti-unification à la promotion.

## Risques / questions ouvertes
- 🔶 Distinguer `Enum.Variant(...)` (construction) de `obj.method(...)` (appel) : par le nom de base (un enum
  connu) — sinon méthode.
