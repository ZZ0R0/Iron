# [23400] Traits user : `class(Trait)` + bornes + méthodes par défaut

- Version : V11 · Milestone : M11 · Statut : draft · Dépend de : 20300 · Invariants : I6, I9

## Objectif
Rendre les **traits utilisateur** pleinement utilisables (chantier C) : une classe **implémente** un trait,
une fonction générique peut le **borner**, un trait peut fournir des **méthodes par défaut**. Projection
propre des traits Rust (I6).

## Périmètre
- **DC-1** : `class Dog(Show):` = « implémente `Show` » → désucré `struct Dog` + `impl Show for Dog` (méthodes
  de la classe matchant la signature du trait). Plusieurs : `class Dog(Show, Ord):`. Base inconnue comme
  trait → erreur claire.
- **DC-2** : `def f[T: Show](x)` → `fn f<T: Show>` ; le moteur connaît `(Show, méthode) → signature` et les
  `impl` (Iron + classes implémentantes) → `x.show()` typé. `Show` émis comme **trait Rust**.
- **DC-3** : `trait Show: def show(self) -> str: <corps>` (corps **optionnel**) → méthode **par défaut** dans
  le trait Rust. Une classe peut ne pas la redéfinir.

## Hors-périmètre
- Dispatch dynamique (`dyn Trait`) — génériques monomorphisés (I6). Traits génériques avancés → `rust { }`.

## Comportement attendu
```
trait Show:
    def show(self) -> str
    def shout(self) -> str:        # méthode par défaut
        return self.show()
class Dog(Show):
    name: str
    def show(self) -> str: return self.name
def display[T: Show](x): return x.shout()
display(Dog(name="Rex"))           # → "Rex"
```

## Contrat / interface
`parse.rs` : `class Name(Base, …):` (bases), trait avec corps de méthode. `ir.rs` : la classe porte ses
traits implémentés. `lower.rs` : `impl Trait for Type` + trait avec défauts. `infer/engine` : `(trait,
méthode)`→sig dans l'env ; borne `T: Show` connue.

## Source maps
I8 : erreurs de trait (méthode manquante, borne non satisfaite) sur la ligne Iron.

## Critères d'acceptation
- `class Dog(Show)` + `def f[T: Show]` + méthode par défaut → compile+run (fixture). Méthode de trait
  manquante → erreur claire. Non-régression `class`/`trait`/`impl` existants.

## Décomposition
→ planif : (1) parse bases + trait-corps ; (2) IR + désucrage impl ; (3) inférence des bornes/méthodes.
