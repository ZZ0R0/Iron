# [11100] Surface : fonctions imbriquées · while/for-else · affectation chaînée · const globales

- Version : V11 · Milestone : M11 · Statut : draft · Dépend de : 10200 · Invariants : I1, I2, I9

## Objectif
Combler les trous de **surface syntaxique** (chantier D), tous par **désucrage** vers des constructions
existantes — zéro nouveauté sémantique runtime.

## Périmètre
- **Fonctions imbriquées** (DD-1) : `def inner(...)` dans un `def` → closure `let inner = |args| { corps }`
  (capture **par valeur**, I1). Inner récursive non supportée v0 → message clair si détectée.
- **while-else / for-else** (DD-2) : `else` exécuté si la boucle finit **sans `break`** → drapeau `__broke`
  (lowering).
- **Affectation chaînée** (DD-3) : `a = b = expr` → `expr` évaluée **une fois**, gauche→droite :
  `__t = expr; a = __t; b = __t`.
- **Constantes globales** (DD-bonus) : `NAME = <littéral>` au **top-level** → `const`/`static` Rust
  (immuable seulement ; mutable global = hors-périmètre I2).

## Hors-périmètre
- État global **mutable** (I2). Inner **récursive** (v0).

## Comportement attendu
```
MAX = 100                      # const globale
def outer(x):
    def dbl(y): return y * 2   # closure imbriquée
    return dbl(x)
def find(xs, target):
    for v in xs:
        if v == target: break
    else:
        return -1               # for-else : non trouvé
    return 1
a = b = 5                       # chaînée
```

## Contrat / interface
`parse.rs` : `def` imbriqué (dans `block`), `else` après `while`/`for`, assignation chaînée, item `const`
top-level. `lower.rs` : closure / drapeau `__broke` / désucrage `__t` / `const`.

## Critères d'acceptation
- Inner fn capturant une variable externe compile+run ; for-else/while-else (break vs non-break) corrects ;
  `a = b = expr` assigne les deux ; `const` global lisible. Fixtures dédiées.
