# [30200] Élision d'emprunt (escape analysis) + warning clone-fallback

- Version : V1
- Milestone : M2+
- Statut : draft
- Dépend de : 30100, 40100 (V0)
- Invariants applicables : I1, I2, I3, I4

## Objectif
Remplacer le **clone-total** de V0 par des **emprunts / moves** là où c'est prouvé sûr, via une
escape analysis. **Optimisation pure** : sémantique strictement inchangée. Clone = fallback (I1) +
warning `--audit` (I4). Modèle **A** (signatures `&T`) validé au cadrage.

## Périmètre
- `OwnershipMap` **réel** (`Clone` / `Move` / **`Borrow`**) par lecture de variable.
- `ParamModes` : par `fn`, chaque param classé `ByValue` (s'échappe) ou `ByRef` (read-only → `&T`).
- `lower` les respecte : signatures `&T`, call sites `&x`, move sans clone, clone + `--audit`.

## Hors-périmètre
- `inout`/`ref` mutation-through-param (I3) → ultérieur ; **`&mut T` non émis en V1**.
- Génériques/traits (V3). Lifetimes nommés (jamais — projection simple, I6).

## Comportement attendu (observable)
- **Param read-only → `&T`** :
  `fn norm2(p: Pt) -> i64: return p.x*p.x + p.y*p.y`
  → `fn norm2(p: &Pt) -> i64 { (p.x*p.x + p.y*p.y) }`, appel `norm2(&p)`. *(V0 : `norm2(p.clone())`.)*
- **Param qui s'échappe → `T` (move)** : `fn id(p: Pt) -> Pt: return p` → `p: Pt`, `return p;`.
- **Dernière utilisation d'un local → move** (pas de clone) ; lecture non-dernière acceptée en `&` → borrow ;
  sinon clone (+ `--audit`).
- **Optimisme borné (I2)** : emprunt **seulement si évidemment sûr**, sinon clone. Un emprunt optimiste
  rejeté par `rustc` **remonte au span Iron** (I8, déjà en place) — jamais d'`unsafe`/corruption.
- `--audit` (off par défaut, I4) : un warning *perf* par clone-fallback restant.

## Contrat / interface
Produit `OwnershipMap` (réel) + `ParamModes`. Consommé par `lower`. **Étend `Disposition` avec `Borrow`**
(ajout rétro-compatible au schéma V0).

## Source maps
N/A (analyse). Les emprunts optimistes rejetés par `rustc` s'appuient sur la remontée existante (I8).

## Critères d'acceptation
- **Sémantique inchangée** : corpus V0 (`ironc/tests/fixtures/`) → sorties **identiques** (diff vide).
- **Moins de `.clone()`** dans le Rust généré du corpus (mesurable, strictement `<`).
- `--audit` liste les clone-fallbacks restants.
- Zéro `unsafe` ; **I1 préservé** (le corpus compile toujours).

## Décomposition
→ `planification/` (fondation → escape analysis → lower → unification).

## Risques / questions ouvertes
- 🔶 **Emprunt optimiste cassant I1** (un programme V0-valide qui ne compile plus). Mitigation :
  **conservateur** (au doute → clone). Surveillé au gate (« compile toujours »).
- ❓ **Échappement fin** : passer un param à un autre `fn` en `ByRef` ne l'échappe pas, en `ByValue` si.
  → dépendance entre signatures (point fixe). **V1 : passe conservatrice 1-shot** (param passé à un appel
  utilisateur ⇒ traité comme s'échappant) ; raffinement point-fixe ultérieur. À confirmer en planif.
