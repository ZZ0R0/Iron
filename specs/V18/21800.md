# [21800] Ergonomie : lever les gotchas du quotidien

- Version : V18
- Milestone : self-suffisance
- Statut : draft
- Dépend de : [21700+] (moteur I15), [70400] (garde)
- Invariants applicables : I11, I12, I13, I15

## Objectif
Supprimer les **frictions quotidiennes** documentées (`docs/gotchas.md` + `RAPPORT_IRON.md` §2.4/2.5/2.7) qui
forcent des contournements ou surprennent. Quatre points, hétérogènes mais tous « ergonomie » : `?`-dans-`main`,
sémantique Python de `int()`/`**`, **propagation de type inter-appels** (§2.4), **annotation de retour
respectée** (§2.5). Objectif : qu'on écrive du Iron **naturel** sans buter.

## Périmètre
- **(a) `?`-dans-`main`** : un `?` dans `main` **auto-promeut** `main` en `Result` (ou diagnostic clair) — au
  lieu de l'erreur « `?` only in a function that returns Result ».
- **(b) `Result[unit]`** : annoter `-> Result[unit]` émet `Result<(), …>` (pas le type `unit`).
- **(c) stdlib Python** : `int(f64)` → cast (pas le parseur de chaîne) ; `f64 ** n` → `powi`/`powf`.
- **(d) §2.4 propagation** : un type concret connu chez l'appelant se propage le long de la chaîne d'appels
  (`HitRecord` à travers `ray_color→shade→shade_lambert`) ; membre **jamais appelé** → inférer du corps ou
  **diagnostiquer** (plus de `__T<n>` qui fuit vers `rustc`).
- **(e) §2.5 annotation de retour** : `def f() -> T:` **impose** `T` ; un `Option` deviné ne **réécrit pas**
  l'annotation — on prouve l'exhaustivité du `return` (`while True` sans `break`…) ou on **diagnostique**.

## Hors-périmètre
- L'inférence Option/Result **légitime** depuis le flux (I11) reste — seul le cas où elle **écrase une
  annotation explicite** (e) change.

## Comportement attendu
```python
def main():                   # (a) `?` ici → main devient Result automatiquement
    cfg = parse("x")?
    print(cfg)
print(int(3.9))               # (c) → 3 (cast, pas parse)
print(2.0 ** 5)               # (c) → 32.0 (powi/powf)
def f() -> Vec3:              # (e) annotation respectée même avec return conditionnel exhaustif
    while True:
        if ok(): return make()
```

## Contrat / interface
- **(a)** si `main` (sans annotation) contient un `?`/`raise`, l'émettre en `-> Result<(), IronError>` + `Ok(())`.
- **(d)** partage le **graphe d'appels** (déjà construit par l'ownership V17 / l'inférence) — propagation à point fixe.
- **(e)** le moteur de flux (`infer/engine/flux.rs`) : annotation présente ⇒ priorité ; exhaustivité prouvée
  ou **diagnostic I8** (jamais de réécriture silencieuse).
- `rustc` filet (I2) partout.

## Critères d'acceptation (validés par [70400])
- **Le raytracer compile SANS** ses annotations de contournement (`cross(self, o: Vec3)`, `rec: HitRecord`,
  `scene: Scene`, `r: Ray`) — ou avec un **diagnostic clair** si le repli (d) ne suffit pas.
- `main` avec `?` compile sans annotation explicite ; `int(3.9)`→3 ; `2.0**5`→32.0 ;
  `f() -> Vec3` reste `Vec3` (pas d'`Option`).
- Corpus [70400] vert (l'inférence Option/Result légitime **préservée**).

  diagnostic = plus prévisible). Décision en planif.
