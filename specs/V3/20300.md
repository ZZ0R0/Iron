# [20300] Système de types avancé : enums + match + traits + génériques

- Version : V3 · Milestone : M5 · Statut : draft · Dépend de : 20100, 40100 · Invariants : I6, I2, I8

## Objectif
4 constructions de type par **projection vers Rust** (I6) + **`rustc` = vérificateur** (I2). L'inférence
Iron reste légère ; les paramètres de type sont **opaques** (rustc fait HM/monomorphisation/exhaustivité).

## Périmètre
- **Enum** `enum E:` + variantes (`Unit` | `V(T, …)`) → `enum` Rust ; construction `E.V(…)`.
- **`match`** (instruction) `match e:` + bras `motif:` bloc → `match` Rust. **Lève la dette V0** (consommation `Option`/`Result`).
- **Trait + impl** `trait T:` / `impl T for Ty:` → `trait`/`impl` Rust ; appel `x.m(args)`.
- **Génériques** `[T]` : `fn f[T](…)`, `struct S[T]:`, bornes `[T: Trait]` → generics Rust.

## Hors-périmètre
Variantes à champs nommés (tuple only V3) ; gardes de motif ; associated types ; HM côté Iron.

## Comportement attendu (Iron → Rust)
- `enum Shape: Circle(f64); Square(f64)` → `enum Shape { Circle(f64), Square(f64) }` ; `Shape.Circle(1.0)` → `Shape::Circle(1.0)`.
- `match s: Shape.Circle(r): … ; _: …` → `match s { Shape::Circle(r) => {…}, _ => {…} }`.
- `match o: Some(x): … ; None: …` (Option, dette V0 levée).
- `trait Area: fn area(self) -> f64` + `impl Area for Shape: …` → `trait`/`impl` Rust ; `s.area()`.
- `fn id[T](x: T) -> T: return x` → `fn id<T>(x: T) -> T { x }`.

## Contrat / interface
AST : `Item::{Enum,Trait,Impl}`, `StmtKind::Match` + `Pattern`, params génériques `[T]` sur fn/struct/enum.
`Type` += `Enum(name)`, `Generic(name)`. Lowering = projection directe.

## Source maps
`match` non exhaustif / erreur générique / borne non satisfaite → erreur `rustc` **remontée** au span Iron (I8, I2).

## Critères d'acceptation
enum+match exécute ; Option/Result filtrés par match ; trait+impl appelé ; générique instancié ≥2 types ;
match non exhaustif → erreur remontée ; zéro `unsafe` ; corpus V0/V1/V2 vert.

## Décomposition
→ `planification/` : enums+match → traits+impl → génériques → unification.

## Risques / questions ouvertes
- 🔶 Résolution de méthode de trait (quel `impl`) — s'appuyer sur rustc autant que possible.
- 🔶 Génériques = profond ; projection + rustc filet (I2). Inférence d'instanciation laissée à rustc.
