# [30400] Ownership avancé : escape point-fixe, move-hors-struct, scoping `for`

- Version : V6 · Milestone : M2++ · Statut : draft · Dépend de : 30200 · Invariants : I1, I2

## Objectif
Lever trois dettes d'ownership : escape analysis **inter-signatures** (point fixe), **move d'un champ hors
d'un struct possédé**, et le **scoping de la variable de `for`** utilisée après la boucle.

## Périmètre
- **Point fixe** (30200 DV2) : un param passé à un autre `fn` en `ByRef` ne s'échappe pas ⇒ itérer jusqu'à
  stabilité des `ParamModes` (au lieu du 1-shot conservateur).
- **Move-hors-struct** (20300 DX2) : `fn first(p: Pair) -> T: return p.a` → `p` possédé (`ByValue`) +
  `return p.a` move partiel (p non réutilisé) → pas de borne `Clone`.
- **Scoping `for`** (D7b) : une variable de boucle utilisée **après** la boucle → hoistée comme une locale.

## Hors-périmètre
Borrow-checker complet côté Iron (rustc reste le filet, I2).

## Comportement attendu (Iron → Rust)
- Emprunt **transitif** : `g(p)` où `g` prend `&T` ⇒ `p` reste `ByRef` chez l'appelant.
- `return p.a` (p possédé) → `return p.a;` (move partiel).
- `for v in xs: …` puis `print(v)` → `v` hoistée, dernière valeur conservée.

## Contrat / interface
`resolve.rs` : itération point-fixe sur `ParamModes` ; détection « champ retourné par valeur » → param
`ByValue` ; collecte des for-vars échappantes pour hoisting.
