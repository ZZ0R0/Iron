# [90100] Corpus de validation — métrique de vérité large

- Version : V6 · Milestone : méta · Statut : draft · Dépend de : (tout) · Invariants : —

## Objectif
La **métrique de vérité** de la méthodo, à l'échelle : correction sémantique `Iron → Rust` et coût du
clone-fallback sur un **corpus large** (centaines/milliers de programmes), pas 22.

## Périmètre
- **Corpus** : programmes Iron variés (générés et/ou écrits) avec **sortie attendue** vérifiable.
- **Harnais** : `ironc run` sur chaque cas → comparer la sortie ; agréger **taux de correction**, **densité de
  clones**, **taux de compilation**, items non couverts.
- **Différé** jusqu'au **gel du langage** (sinon on chiffre sur cible mouvante — refus méthodo).

## Hors-périmètre
Fuzzing de `rustc` ; benchmarks de perf runtime.

## Comportement attendu
Un rapport chiffré reproductible : « N/N corrects, X clones / KLOC, Y% compilent, Z constructions non couvertes ».

## Contrat / interface
Dossier `corpus/` + un runner (`ironc`-driven) + un script d'agrégation. Sortie : tableau de métriques.
