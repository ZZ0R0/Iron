# [80200] Stdlib élargie : `sum`/`concat` génériques, tri, IO, chaînes

- Version : V6 · Milestone : M6+ · Statut : draft · Dépend de : 80100 · Invariants : I5, I7

## Objectif
Compléter le prélude (V4) : génériciser, ajouter tri, IO (stdin) et opérations de chaînes — wrappers fins (I5).

## Périmètre
- **`sum(lst)`** générique (`list[T: Add]` → `T`), pas seulement `i64`.
- **`concat`** sur listes ; jonction de chaînes.
- **`sort(lst)`** (mute, `T: Ord`).
- **IO** : `input()` (lire une ligne stdin → `str`).
- **Chaînes** : `split(s, sep)`, `upper(s)`, `lower(s)`, `index_of(s, sub)`.

## Hors-périmètre
Formatage avancé ; fichiers ; réseau (→ via interop V2/`.iri`).

## Comportement attendu (Iron → Rust)
- `sum(xs)` → `xs.iter().cloned().sum::<T>()` · `sort(xs)` → `xs.sort()` · `input()` → lecture `stdin().read_line` ·
  `split(s, ",")` → `s.split(",").map(str).collect()` · `upper(s)` → `s.to_uppercase()`.

## Contrat / interface
Built-ins (comme V4) avec types de retour génériques ; ceux nécessitant un trait s'appuient sur rustc (bornes).

## Source maps
N/A (built-ins).

## Critères d'acceptation
Programme utilisant `sum` générique + `sort` + `input` + `split`/`upper` → compile + exécute.
