# [70100] Driver cargo + CLI `ironc`

- Version : V0
- Milestone : M2
- Statut : draft
- Dépend de : 40100
- Invariants applicables : —

## Objectif
CLI `ironc build | run` : matérialiser le `TokenStream` en projet cargo (via `prettyplease`), invoquer `cargo`, relayer compilation et exécution.

## Périmètre
`ironc build <f.irn>` → `Cargo.toml` + `src/main.rs` (pretty-printé) dans un dossier de sortie ; `ironc run` = build + `cargo run`. Capture de la sortie `cargo` (passée à 60100). Mono-fichier V0 (§4.7).

## Hors-périmètre
Lowering (→ 40100) ; remontée diagnostics (→ 60100) ; multi-fichiers / packaging (→ ultérieur).

## Comportement attendu (observable)
- `ironc build` produit un projet cargo **compilable** et déterministe.
- `ironc run` compile puis exécute ; code de retour relayé.
- Sortie `cargo` (diagnostics JSON) récupérée pour 60100.

## Contrat / interface
Consomme `(TokenStream, SourceMap)` (40100), appelle `prettyplease` + `cargo`. Produit le projet + relaie exécution/diagnostics.

## Source maps
Transporte la `SourceMap` vers 60100 ; ne la modifie pas.

## Critères d'acceptation
- `ironc run` sur le programme V0 → `cargo` **vert** → **sortie correcte** (gate e2e §6).
- Projet généré reproductible (même entrée → mêmes fichiers, modulo `prettyplease`).
