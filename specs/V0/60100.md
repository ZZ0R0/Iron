# [60100] Source maps + remontée diagnostics rustc

- Version : V0
- Milestone : M3
- Statut : draft
- Dépend de : 40100
- Invariants applicables : I8, I2
- **⚠ PRIORITÉ DE DÉRISQUAGE** (risque n°1, `generator §8`) — à attaquer en premier dès que 40100 produit du Rust.

## Objectif
Établir le mapping `Span` `.irn` ↔ position Rust générée (I8), **survivant à `prettyplease`**, et **remonter** les diagnostics `rustc`/`cargo` vers le `Span` Iron d'origine.

## Périmètre
Ré-localisation des marqueurs (produits par 40100) dans le Rust **après** pretty-print → table `Span_irn ↔ (ligne, col) Rust`. Parsing des diagnostics `cargo` (JSON) → re-pointage sur `Span` Iron.

## Hors-périmètre
Production des marqueurs (→ 40100) ; build (→ 70100).

## Comportement attendu (observable)
- Après `prettyplease`, chaque marqueur est **re-localisé** à sa position Rust finale ; on en déduit `Span_irn ↔ Rust`.
- Une erreur `rustc` (forcée) est **ré-affichée pointant le `Span` Iron** (I2 : pire cas = erreur remontée proprement, jamais du Rust brut).
- Granularité : **instruction** d'abord (dérisquage), **expression** comme cible V0 (§4.6).

## Contrat / interface
Consomme `SourceMap` (40100) + sortie `cargo` JSON (70100). Produit le mapping + les diagnostics remontés.

## Source maps
**C'est le composant source maps.** Cœur de I8.

## Critères d'acceptation
- Une erreur de type forcée dans un `.irn` → message pointant la **bonne ligne Iron** (pas du Rust).
- Mapping robuste au reformatage : un re-`prettyplease` ne casse pas le pointage.
