# [2.2] Émission auto des types externes (fermeture du graphe)

- Spec parente : 51200 · Version : V8 · Dépend de : 1.1, 1.2 · Statut : todo · **Vague 2** (parallèle — `bind/emit_types.rs`)

## But
Émettre un `extern type` opaque pour chaque struct/enum référencé par une signature bindée, **transitivement**.

## Fichiers touchés
`src/bind/emit_types.rs` (uniquement).

## Étapes
1. Collecter tous les `Type::Extern(name)` des signatures (fns + méthodes + ctors).
2. Résoudre le chemin Rust via `.paths` rustdoc ; émettre `extern type <name> = "<path>"`.
3. Fermeture transitive jusqu'au point fixe (un type tire ses types de méthodes) ; idempotent.
4. Types hors-crate (`std::…`) → handle opaque sans méthodes. Borne de profondeur + log « N types émis ».

## Critère de done
`bind regex` : `Regex`/`Captures`/`Match`… émis, **aucune réf pendante** ; point fixe sur graphe cyclique
(test) ; build + corpus VERT.

## Notes

crate → opaque non-paramétré (usage paramétré → 2.4).
