## But
Figer la projection récursive type-Rust → type-Iron : scalaires larges, texte, constructeurs possédés, réfs
externes. C'est la **convention partagée** que tous les producteurs de la vague 2 appellent (D1).

## Fichiers touchés
`src/bind/types.rs` (`map_type`, `is_borrowed_return`) · tests dans `bind/types.rs` ou `tests/`.

## Étapes
1. `map_type(&Value) -> Option<Type>` récursive : scalaires (i8…u128/usize/f32/char/bool), `&str`/`String`→`str`,
   `Vec`→`list`, `Option`/`Result`, `HashMap`/`BTreeMap`→`dict`, `HashSet`/`BTreeSet`→`set`, `Box`/`Rc`/`Arc`→
   intérieur, tuple, `&[T]`→`list`, réf de struct/enum du crate → `Type::Extern`, `&T` entrée → `T`.
2. `is_borrowed_return(&Value) -> Option<&Value>` (sortie `&T`/`Option<&T>`/`&[T]`) pour 51300.
3. Non mappable (générique nu, `dyn`, assoc, ptr brut) → `None`. **Aucun widening.**
4. Tests : un cas par famille + anti-widening (`i32` ≠ `i64`).
