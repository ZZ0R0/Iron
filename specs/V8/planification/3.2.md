# [3.2] Lowering complet des appels externes + glue des 4 idiomes

- Spec parente : 40200 · Version : V8 · Dépend de : 3.1, 2.3, 2.4 · Statut : todo · **Vague 3** (séquentielle — `lower`)

## But
Émettre le Rust réel de tous les appels externes + la glue des 4 idiomes (au-delà du squelette `Clone` de 1.3).

## Fichiers touchés
`src/lower.rs` (branche appels externes) · `src/sourcemap` (rattachement I8).

## Étapes
1. Appel libre/namespacé/méthode/ctor selon `recv` → `TokenStream` (I10).
2. Réinjection `&`/`&mut`/`.to_string()`/`.as_str()` selon la cible Rust.
3. Glue idiomes : `Clone`→`.clone()`/`.cloned()` (+warning perf I4) ; `Collect`→`.collect::<Vec<_>>()` ;
   `Builder`→appel mutateur, retour jeté ; `Closure(idx)`→lambda Iron en closure Rust.
4. Instance-pinning (2.4) : `rust_target` avec `::<…>` émis **verbatim**.
5. I8 : chaque appel + sa glue portent le `Span` de l'appel Iron.

## Critère de done
Les 4 idiomes émettent le Rust attendu (test `Iron → Rust généré` par idiome) ; **0 `unsafe`** ; erreur `rustc`
sur appel externe → `Span` Iron (I8) ; warning `[clone]` sous `--audit` seulement ; corpus VERT + e2e réel re-validé.
