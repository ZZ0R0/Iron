# [2.5] Namespacing (`extern mod` + chemins de module)

- Spec parente : 51500 · Version : V8 · Dépend de : 1.1, 1.2 · Statut : todo · **Vague 2** (parallèle — `bind/modules.rs`)

## But
Grouper les items bindés sous un nom de module (`regex.escape(...)`) pour éviter les collisions à plat et
offrir une surface Python.

## Fichiers touchés
`src/bind/modules.rs` (groupement + `resolve`) · `Bindings::resolve` (signature figée en 1.1).

## Étapes
1. `group_modules(&mut Bindings)` : regrouper par dernier segment de sous-module rustdoc → `b.mods`.
2. `Bindings::resolve(path: &[&str]) -> Option<&ExternFn>` : `["regex","escape"]` → l'`ExternFn`.
3. Cohabitation avec `import` Iron (70200) : même surface `mod.f(...)` ; conflit de nom → erreur claire.

## Critère de done
`bind regex` produit `extern mod regex` ; `regex.escape("a.b")` compile + s'exécute ; deux crates à `parse`
homonyme → pas de collision ; build + corpus VERT.

## Notes
Ownership disjoint : `modules.rs`. La résolution `resolve` est consommée par `infer`/`lower` (3.1/3.2). Défaut :
crate = module racine + sous-modules à plat.
