# [2.1] Extraction POO : méthodes & constructeurs depuis `impl`

- Spec parente : 51100 · Version : V8 · Dépend de : 1.1, 1.2 · Statut : todo · **Vague 2** (parallèle — `bind/methods.rs`)

## But
Parcourir les `impl` inhérents et peupler `ctors`/`methods` des `ExternType` (le cœur de la POO bindée).

## Fichiers touchés
`src/bind/methods.rs` (uniquement).

## Étapes
1. Parcourir `index` : items `inner.impl` inhérents (`trait==null`), non synthétiques/blanket, `for` public.
2. Pour chaque `function` publique de `impl.items` : 1ᵉʳ param `self`/`&self`/`&mut self` → méthode (`recv`) ;
   sinon → ctor (`recv=None`).
3. Projeter la signature via `map_type` (1.2) ; non mappable → sauté + compté.
4. Rattacher au `ExternType` (créer l'entrée si absente ; fusionner si plusieurs `impl`).

## Critère de done
`bind regex` : `Regex` porte `is_match`/`find`/`captures`… ; `recv` correct (`self`/`&self`/`&mut self`) ;
ctors distingués ; non-mappables comptés ; build + corpus VERT.

## Notes
Ownership disjoint : ne touche QUE `methods.rs`. Méthodes génériques sur la méthode → sautées (→ 2.4). Collisions
de noms multi-`impl` → 1ʳᵉ gardée + comptée.
