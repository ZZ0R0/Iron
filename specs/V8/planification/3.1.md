# [3.1] Inférence complète des appels/méthodes/types externes

- Spec parente : 21100 · Version : V8 · Dépend de : 1.3, 2.1, 2.2, 2.5 · Statut : todo · **Vague 3** (séquentielle — `infer`)

## But
Compléter l'inférence (au-delà du squelette 1.3) : ctors, namespacing, instances, vérification d'arguments.

## Fichiers touchés
`src/infer/*` (résolution des appels externes, `TypeMap`).

## Étapes
1. Enregistrer chaque `ExternType.iron_name` comme `Type::Extern`.
2. Résoudre `obj.method(args)`, `T.ctor(args)`, `mod.fn(args)` (via `Bindings::resolve`, 2.5) → type retour.
3. Vérifier arité + types des arguments → erreur Iron (Span) si mismatch (pas attendre `rustc`).
4. `Result[T]`/`Option[T]` retournés s'intègrent au flux `?`/`try` (I11/I13).
5. Message « méthode introuvable » qui liste les méthodes dispo + signale si sautée au binding.

## Critère de done
Un programme Iron utilisant `regex` (ctor + méthode + namespacing) type-checke ; `r.is_match(123)` → erreur
Iron claire ; `?` déplie `Result[Regex]` ; corpus VERT (squelette 1.3 toujours vert).

## Notes
Surface partagée `infer` → séquentiel avant 3.2. Méthode externe prime sur le handle. Coordonné avec
`Type::Extern` figé en 1.1.
