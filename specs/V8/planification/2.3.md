# [2.3] Reconnaisseurs d'idiomes (builder / getter / iterator / closure)

- Spec parente : 51300 · Version : V8 · Dépend de : 1.1, 1.2 · Statut : todo · **Vague 2** (parallèle — `bind/idioms.rs`)

## But
Détecter les 4 idiomes sur chaque `ExternFn`/méthode, normaliser la signature Iron, poser le tag. **Le levier
anti-armée** : 73–100 % du résidu mesuré.

## Fichiers touchés
`src/bind/idioms.rs` (uniquement).

## Étapes
1. **Builder** : `recv=ByRefMut` + retour `&mut Self`/`Self` → retour `unit`, tag `Builder`.
2. **Getter** : `is_borrowed_return` (1.2) → retour possédé `T`/`Option[T]`/`list[T]`, tag `Clone` (D4, I1/I4).
3. **Iterator** : retour `impl Iterator`/type avec `impl Iterator for` → `list[T]`, tag `Collect`.
4. **Closure** : param `F: Fn`/`impl Fn`/`&dyn Fn` → type `fn(...)->...`, tag `Closure(idx)`.
5. Ordre **builder avant getter** ; ambiguïté → **ne pas taguer** (sauté + compté).

## Critère de done
`bind regex` : builders (`RegexBuilder`), getters (`Captures::get`), iterators (`find_iter`) tagués ; un
`&mut Self` jamais tagué `Clone` (test ordre) ; couverture `regex`/`serde_json` ≥ cadrage ; build + corpus VERT.
