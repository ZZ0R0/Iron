# [2.4] Instance-pinning (monomorphisation à la demande)

- Spec parente : 51400 · Version : V8 · Dépend de : 1.1, 1.2 · Statut : todo · **Vague 2** (parallèle — `bind/instantiate.rs`)

## But
Permettre d'épingler une instance concrète d'un générique (couche assistée B) : `--instantiate` + `::<…>` dans
le `rust_target` d'un `.iri` curé.

## Fichiers touchés
`src/bind/instantiate.rs` (parseur de directive) · point d'extension du parseur `.iri` (signature figée en 1.1
pour accepter `::<…>` dans `rust_target` — pas de re-touche de `mod.rs`).

## Étapes
1. `parse_instantiation("path::<T> as name(sig) -> ret") -> CResult<ExternFn>`.
2. Accepter les type-args explicites dans `rust_target` (validés : type-arg = réf externe connue ou scalaire).
3. Multi type-args (`HashMap::<String,i64>`). Type-arg inconnu → erreur claire.

## Critère de done
`--instantiate "serde_json::from_str::<i64> as parse_int(s: str) -> Result[i64]"` → `.iri` valide,
`parse_int("42")` compile + renvoie `42` ; type-arg inconnu → erreur ; build + corpus VERT.

## Notes
Ownership disjoint : `instantiate.rs`. La borne de trait est vérifiée par `rustc` (I2, filet) → erreur remontée
I8, jamais binding faux. `rust_target` passé **verbatim** à la lower (3.2).
