# [50900] Format `.iri` v2 + `Bindings` IR + pipeline `emit` modulaire

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 50200, 50300, 50400 · Invariants : I6, I7, I10

## Objectif
Geler **le contrat** de toute la V8 : le format `.iri` v2 (ce que `bind` **produit** et ce que `infer`/`lower`
**consomment**) et sa représentation `Bindings` en IR. Aujourd'hui le `.iri` n'exprime que des `extern fn`
plates et des `extern type` opaques sans API. V2 ajoute les **types externes à méthodes/constructeurs**, une
**grammaire de types riche**, les **tags d'idiomes** et le **namespacing**. C'est la fondation D0 : figée
avant tout fan-out.

## Périmètre
- **Grammaire `.iri` v2** (sur-ensemble rétro-compatible de 50200) :
  - `crate <name> = "<version>"` (inchangé → dépendance Cargo).
  - `extern fn <name>(<params>) -> <ret> = "<rust::path>" [<idioms>]` (tags d'idiomes ajoutés).
  - `extern type <Name> = "<rust::path>":` suivi d'un **bloc indenté** de `fn` (ctors = sans `self`,
    méthodes = 1ᵉʳ param `self`/`&self`/`&mut self`).
  - `extern mod <name>:` + liste d'items → préfixe d'appel Iron (50900 réserve la syntaxe ; logique en 51500).
  - Types dans les signatures : grammaire riche (déléguée à 51000 pour la projection, ici juste **parsée**).
- **`Bindings` IR** (dans `ir.rs`) : structures gelées (cf. Contrat).
- **Pipeline `emit` modulaire** : éclater `bind.rs` en module `bind/` (`mod.rs` + fichiers producteurs) pour
  que les pistes de la vague 2 aient un **ownership disjoint**. `emit` (dans `mod.rs`) orchestre des
  producteurs purs `(&rustdoc_item) -> Option<IriDecl>`.

## Hors-périmètre
- La **projection** des types (`map_type`) → 51000. La **détection** méthodes/idiomes/types → 51100/51200/51300.
- L'**interprétation** du `.iri` (types/glue) → 21100 (infer) / 40200 (lower).

## Comportement attendu
Un `.iri` v2 écrit à la main est **parsable** et produit un `Bindings` complet. Exemple cible :
```
crate regex = "1.11"
extern type Regex = "regex::Regex":
    fn new(pattern: str) -> Result[Regex]            = "regex::Regex::new"
    fn is_match(self, text: str) -> bool             = "is_match"
    fn find(self, text: str) -> Option[(i64, i64)]   = "find" [clone]
extern fn escape(s: str) -> str = "regex::escape"
```
→ `Bindings { crates: [("regex","1.11")], funcs: [escape…], types: [Regex { ctors:[new], methods:[is_match, find{idiom:Clone}] }] }`.

## Contrat / interface
`ir.rs` (gelé) :
```
Bindings { crates: Vec<(String,String)>, funcs: Vec<ExternFn>, types: Vec<ExternType>, mods: Vec<ExternMod> }
ExternType { iron_name: String, rust_path: String, ctors: Vec<ExternFn>, methods: Vec<ExternFn> }
ExternFn   { iron_name: String, params: Vec<(String, Type)>, ret: Type,
             rust_target: String, recv: Option<Recv>, idioms: Vec<Idiom> }
Recv  = ByValue | ByRef | ByRefMut
Idiom = Builder | Clone | Collect | Closure(usize)
ExternMod { name: String, items: Vec<String> }
```
`bind/mod.rs` : `parse_iri(&str) -> CResult<Bindings>` (le parseur du format) ; `emit(rustdoc, crate) -> String`
(orchestre les producteurs). `driver::load_bindings` renvoie ce `Bindings`.

## Source maps
N/A pour `bind`/`parse_iri` (hors pipeline de compilation). Les `ExternFn.rust_target` serviront à 40200 pour
attacher les spans I8 ; 50900 ne génère pas de Rust.

## Critères d'acceptation
- `parse_iri` lit le `.iri` v2 d'exemple → `Bindings` exact (types, méthodes, ctors, idiomes, recv).
- **Rétro-compat** : tous les `.iri` v1 existants (`libm.iri`, `gen_libm.iri`, `math.iri`) parsent identique.
- `bind.rs` éclaté en `bind/` ; `cargo build` vert ; le corpus passe (arms par défaut câblés).
- Un `.iri` v2 invalide (bloc mal indenté, idiome inconnu) → **erreur claire**, jamais un `Bindings` faux.

## Décomposition
→ planif `1.1` : structures IR + `parse_iri` v2 + éclatement `bind/` + arms par défaut (build vert).

## Risques / questions ouvertes
- 🔶 Le parseur `.iri` : réutiliser le lexer/parser Iron (les `extern …` y vivent déjà via `use`) ou un
  mini-parseur dédié dans `bind/` ? **Décision** : mini-parseur dédié (le `.iri` est un format de données, pas
  du code Iron) — découple bind de parse.rs, évite les collisions vague 2.
- 🔶 Idiomes inconnus dans un `.iri` curé → erreur stricte (pas d'ignore silencieux), pour ne pas masquer un
  binding cassé.
