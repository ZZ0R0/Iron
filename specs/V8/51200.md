# [51200] Émission auto des types externes (fermeture du graphe)

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 50900, 51000, 51100 · Invariants : I6, I5

## Objectif
Fermer le **graphe de types**. Quand une fn ou une méthode bindée mentionne un struct/enum du crate (en
paramètre ou en retour), ce type doit exister côté Iron en tant que **handle opaque** (D2), sinon le `.iri`
est incomplet (référence pendante). Cette spec émet automatiquement un `extern type X = "crate::X"` pour
**chaque** type référencé, **transitivement**, jusqu'au point fixe.

## Périmètre
`bind/emit_types.rs` :
- Collecter l'ensemble des `Type::Extern(name)` apparus dans toutes les signatures bindées (fns + méthodes + ctors).
- Pour chaque type : résoudre son **chemin Rust** via `.paths` rustdoc-json, émettre `extern type <name> = "<path>":`.
- **Fermeture transitive** : un type émis dont les méthodes (51100) référencent d'autres types → les ajouter ;
  itérer jusqu'au point fixe.
- Types externes au crate (`std::…`, autre crate) : émis comme handle opaque **sans** méthodes (on n'a pas leur
  rustdoc) — utilisables en pass-through, méthodes via `rust:` si besoin.
- Type opaque (D2) : **aucun champ** exposé. L'interaction passe par les méthodes/ctors.

## Hors-périmètre
- L'API (méthodes/ctors) des types → 51100. Le namespacing → 51500.
- L'inférence/lowering de l'usage du handle → 21100/40200.

## Comportement attendu
```
extern fn compile(pat: str) -> Regex = "regex::Regex::new"   # référence Regex
```
→ force l'émission de :
```
extern type Regex = "regex::Regex":
    … (méthodes via 51100)
```
Transitif : si `Regex` a `fn captures(self, …) -> Captures`, alors `Captures` est émis à son tour.

## Contrat / interface
`bind/emit_types.rs` : `pub fn close_type_graph(rustdoc: &Value, b: &mut Bindings)` — ajoute/complète
`b.types` jusqu'au point fixe. Idempotent. Un type déjà présent n'est pas dupliqué.

## Source maps
N/A (`bind` hors pipeline).

## Critères d'acceptation
- `bind regex` : `Regex`, `Captures`, `Match`, … tous émis (aucune réf pendante dans le `.iri`).
- Point fixe atteint (pas de boucle infinie sur types mutuellement récursifs — test sur graphe cyclique).
- Un type `std` référencé (`std::time::Duration`) → handle opaque sans méthodes, `.iri` reste valide.

## Décomposition
→ planif `2.2` : collecte des réfs, résolution `.paths`, émission + fermeture transitive (point fixe).

## Risques / questions ouvertes
- 🔶 Explosion du graphe (un type tire 200 types) → borne de profondeur + log « N types émis » (pas de cap
  silencieux, cf. méthodo « no silent caps »).
- 🔶 Types génériques du crate (`struct Wrap<T>`) → émis comme opaque non-paramétré (handle) ; usage
  paramétré → couche B (51400). Documenté.
