# [90300] Corpus de binding réel (regex / serde_json / csv) — gate V8

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 51100, 51200, 51300, 51400, 51500, 21100, 40200 · Invariants : I2, I7, I8

## Objectif
**La boucle de vérité de V8.** Prouver, sur de **vrais crates**, que l'auto-binding produit une interface
Iron utilisable en **style Python**. On binde 3 crates représentatifs (un orienté-données `csv`, un
orienté-traits `serde_json`, un mixte `regex`), on écrit des programmes Iron qui les utilisent via leur POO,
et on vérifie compilation + exécution + **sortie identique** à un oracle. C'est le **gate V8**.

## Périmètre
- **`ironc bind`** de `regex`, `serde_json`, `csv` → `.iri` v2 riches (types + méthodes + idiomes), éventuellement
  complétés par quelques lignes d'instance-pinning (51400) pour `serde_json` (génériques).
- **Programmes Iron** (≥ 1 par crate, multi-fichiers) utilisant l'API en style Python :
  - `regex` : `Regex.new`, `is_match`, `find`, `replace_all`, `captures`.
  - `serde_json` : parse/serialize d'un type concret épinglé (`Value` ou struct).
  - `csv` : `Reader`/`Writer`, itération d'enregistrements.
- **Oracle** : un équivalent (Rust direct, ou sortie attendue figée) ; comparaison **caractère près**.
- **Mesure de couverture** : % de l'API publique des 3 crates atteint (auto + assisté + idiomes), reporté.

## Hors-périmètre
- Le résidu dur (0–6 %) : documenté comme `rust:`/`.iri` curé, **non** exigé par le gate.
- Crates async/GUI → hors V8 (V9+).

## Comportement attendu
Un programme Iron du type :
```
use "regex.iri"
def main():
    r = regex.Regex.new("(\\d+)-(\\d+)")
    for line in lines:
        if r.is_match(line):
            print(r.replace_all(line, "X"))
```
compile (Rust vert, 0 `unsafe`), s'exécute, et sa sortie **égale** l'oracle.

## Contrat / interface
Étend le harnais `tests/gate.sh` : un sous-dossier `tests/binding/` (`<crate>/main.irn` + `.iri` + oracle).
Le gate agrège : OK/KO, couverture mesurée, clones de getters (compteur I4), `unsafe` (doit être 0).

## Source maps (I8)
Le gate **vérifie la remontée I8** : une erreur introduite volontairement dans un appel externe doit pointer
le `Span` Iron correct (test de non-régression des source maps sur le chemin externe).

## Critères d'acceptation
- `regex`, `serde_json`, `csv` : ≥ 1 programme Iron chacun, **compile + s'exécute + sortie = oracle**.
- Couverture mesurée ≥ **90 %** de l'API publique des 3 crates (auto+assisté+idiomes).
- **0 `unsafe`** dans tout le Rust généré (I2).
- Remontée I8 vérifiée sur un appel externe fautif.
- Gate VERT intégré au corpus existant (aucune régression V0→V7).
