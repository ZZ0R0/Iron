# [51000] `map_type` récursif : scalaires larges, types possédés, réfs externes

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 50900 · Invariants : I6, I7

## Objectif
Remplacer la projection actuelle (`i64/f64/bool` seulement → 0 % sur tout vrai crate) par une **projection
récursive** d'un ensemble **fermé** de constructeurs Rust vers les types Iron. C'est **la convention de
projection partagée** (D1) : tous les producteurs de la vague 2 l'appellent ; si elle diverge, deux pistes
projettent `HashMap` différemment → intégration cassée. Gelée avec la fondation.

## Périmètre
`bind/types.rs` : `map_type(&rustdoc_type) -> Option<Type>`, récursive :
- **Scalaires** (I6) : `i8…i128`, `u8…u128`, `usize/isize`, `f32/f64`, `bool`, `char`. Mapping **exact**.
- **Texte** : `&str`, `String` → `str`.
- **Constructeurs possédés** : `Vec<T>`→`list[T]`, `Option<T>`, `Result<T,E>`→`Result[T]` (E ignoré, I13),
  `HashMap<K,V>/BTreeMap`→`dict[K,V]`, `HashSet/BTreeSet`→`set[T]`, `Box<T>/Rc<T>/Arc<T>`→`T` (intérieur),
  `(A, B, …)`→tuple, `&[T]`→`list[T]` (entrée).
- **Réf de type externe** : un chemin résolu vers un struct/enum du crate → `Type::Extern(iron_name)`
  (l'émission du type lui-même → 51200).
- **Emprunts en entrée** : `&T`/`&mut T` → `T` (la lower réinjecte `&`/`&mut` ; cf. 40200).
- Non mappable (générique nu `T`, `dyn Trait`, type associé, pointeur brut) → `None` → **sauté + compté** (D5).

## Hors-périmètre
- Le **retour** emprunté `-> &T` (idiome getter) → détection en 51300, glue en 40200 (ici `&T` en sortie =
  mappé vers `T` *uniquement* si 51300 a posé le tag `Clone` ; sinon `None`).
- L'émission des `extern type` référencés → 51200.

## Comportement attendu
- `pub fn escape(s: &str) -> String` → `escape(s: str) -> str`.
- `pub fn parse(s: &str) -> Vec<i64>` → `parse(s: str) -> list[i64]`.
- `pub fn pairs(&self) -> HashMap<String, i64>` → `pairs(self) -> dict[str, i64]`.
- `pub fn build() -> Regex` (Regex = type du crate) → `build() -> Regex` (réf externe).
- `pub fn weird<T: Trait>(x: T)` → **sauté** (générique nu → couche B, cf. 51400).

## Contrat / interface
`bind/types.rs` : `pub fn map_type(t: &Value) -> Option<Type>` + `pub fn is_borrowed_return(t: &Value) -> Option<&Value>`
(pour 51300). Lit `.index`/`.paths` rustdoc-json (≥ v57, dégrade si champ absent). **Aucun widening.**

## Source maps
N/A (`bind` hors pipeline).

## Critères d'acceptation
- Table de cas (un test par famille) : scalaires larges, `Vec`/`Option`/`Result`/`HashMap`/`HashSet`/tuple,
  `&str`/`String`, réf externe → projection attendue exacte.
- `bind regex` : le nombre d'`extern fn`/méthodes mappées passe de **0** à **> 0** (mesuré).
- Un `i32` n'est **jamais** projeté `i64` (test anti-widening).

## Décomposition
→ planif `1.2` : `map_type` récursif (toutes familles) + `is_borrowed_return` + tests par famille.

## Risques / questions ouvertes
- 🔶 `Result<T, E>` : on jette `E` (I13, `IronError` unifié). Acceptable au binding (la lower mappe l'erreur
  Rust → `IronError`).
- 🔶 `Cow<str>`, `OsString`, `PathBuf` : projetés `str` ? **Décision** : `Cow<str>`→`str` ; `PathBuf/OsString`
  → `str` (la lower réinjecte la conversion). Documenté, dégrade si exotique.
