# [40200] Lowering des appels externes + glue des idiomes

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 50900, 51300, 21100 · Invariants : I2, I8, I10

## Objectif
Émettre le **Rust réel** des appels externes — c'est ici que les idiomes (51300) deviennent du code. Pour
chaque appel d'`ExternFn`/méthode/ctor, produire le `TokenStream` (I10) qui appelle le `rust_target`, en
réinjectant emprunts/conversions et en appliquant la **glue d'idiome**. Respecte I2 (jamais d'`unsafe`) et I8
(chaque appel reçoit le `Span` Iron).

## Périmètre
`lower` (étend le lowering des appels existant) :
- **Appel libre / namespacé** : `mod.f(a)` → `rust::path(<args ajustés>)`.
- **Méthode** : `obj.m(a)` selon `recv` → `RustPath::m(&obj, a)` / `(&mut obj, a)` / `(obj, a)`.
- **Constructeur** : `T.new(a)` → `rust::T::new(a)`.
- **Réinjection** : param Iron `str` → `&x` ou `x.as_str()` si la cible attend `&str` ; `&mut` pour `inout`.
- **Glue d'idiome** (depuis `ExternFn.idioms`) :
  - `Clone` (getter, D4) : envelopper le retour `.clone()` / `.cloned()` (Option) → valeur possédée. **Émettre
    le warning perf I4** (`IRN-Lxxx`, `--audit`).
  - `Collect` (iterator) : `<expr>.collect::<Vec<_>>()` → `list[T]`.
  - `Builder` (`recv ByRefMut`, retour `unit`) : émettre l'appel mutateur, **jeter** le `&mut Self` retourné.
  - `Closure(idx)` : passer la lambda Iron comme closure Rust (`|x| …`), types laissés à `rustc` (I2).
- **Instance-pinning** (51400) : `rust_target` avec `::<…>` émis **verbatim**.

## Hors-périmètre
- Décider du `recv`/des idiomes (figé au binding 51100/51300). Ici on **applique** le tag.

## Comportement attendu
```
r = regex.Regex.new("a+")        →  let r = regex::Regex::new("a+");
ok = r.is_match("aaa")           →  let ok = regex::Regex::is_match(&r, "aaa");
m = caps.get(0)                  →  let m = caps.get(0usize).cloned();          // [clone] + warning perf
spans = r.find_iter("aaa")       →  let spans = r.find_iter("aaa").map(|x| (x.start() as i64, x.end() as i64)).collect::<Vec<_>>();   // [collect]
b.case_insensitive(True)         →  RegexBuilder::case_insensitive(&mut b, true);   // [builder], retour jeté
```

## Contrat / interface
`lower` : nouvelle branche dans l'émission des appels, pilotée par `Bindings` (résolu via `infer`/`resolve`).
Chaque `TokenStream` d'appel externe est enregistré dans la `SourceMap` avec le `Span` de l'appel Iron.

## Source maps (I8 — OBLIGATOIRE)
Chaque appel externe émis attache son `Span` `.irn` à la ligne Rust générée, **comme tout autre appel** (I8).
La glue d'idiome (`.clone()`, `.collect()`, mutation) hérite du **même `Span`** que l'appel : une erreur `rustc`
sur la glue remonte au bon emplacement Iron. Le warning perf des getters (`[clone]`) porte le `Span` de l'appel.

## Critères d'acceptation
- Les 4 idiomes émettent le Rust attendu (test par idiome, `Iron → Rust généré`).
- `0 unsafe` dans tout le Rust généré (I2, vérifié par le gate).
- Une erreur `rustc` sur un appel externe (mauvais type non rattrapé par infer) remonte au `Span` Iron (I8).
- Le warning perf `[clone]` apparaît sous `--audit`, absent sans (I4).

## Décomposition
→ planif `1.3` (minimal : appel méthode + idiome `Clone`) puis `3.2` (complet : 4 idiomes, recv, réinjection, instances).

## Risques / questions ouvertes
- 🔶 Réinjection `&str`/`String` : la cible attend `&str` ou `String` ? Lire la signature Rust originale (gardée
  dans `rust_target`/rustdoc) — défaut `&x`, `.to_string()` si `String` attendu. Testé.
- 🔶 `Collect` sur un itérateur d'`Item` non scalaire (ex. `Match`) → map vers le tuple/handle projeté ; cas
  complexe → résidu dur (non tagué en amont par 51300).
