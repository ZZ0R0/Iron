# [51300] Reconnaisseurs d'idiomes : builder / getter / iterator / closure

- Version : V8 · Milestone : M8 · Statut : draft · Dépend de : 50900, 51000, 51100 · Invariants : I1, I4, I6

## Objectif
**Le levier anti-armée.** La mesure montre que 73–100 % du résidu « non bindable » est en fait **4 idiomes
Rust récurrents**. Les reconnaître **une fois** dans le binder, et émettre une signature Iron **normalisée**
+ un **tag**, convertit la majeure partie du « C » en API utilisable — pour **tous** les crates. La glue Rust
correspondante est émise par le lowering (40200) ; le `.iri` reste déclaratif (D3).

## Périmètre
`bind/idioms.rs` : sur chaque `ExternFn`/méthode extraite, détecter et taguer :
- **Builder** : `recv = ByRefMut` **et** retour `&mut Self` (ou `Self`). → signature normalisée `recv ByRefMut`,
  retour `unit`, tag `Builder`. (Iron mute en place ; on jette le `&mut Self`.)
- **Getter** : retour emprunté `&T`/`Option<&T>`/`&[T]` (51000 `is_borrowed_return`). → retour projeté **possédé**
  `T`/`Option[T]`/`list[T]`, tag `Clone` (D4 : `.clone()`/`.cloned()`, cohérent I1, warning perf I4).
- **Iterator** : retour `impl Iterator<Item=T>` ou type connu `…Iter`. → retour `list[T]`, tag `Collect`.
- **Closure** : un param est `F: Fn(A…)->B` (générique borné Fn) ou `impl Fn`/`&dyn Fn`. → param projeté
  `fn(A…)->B` (type fonction Iron), tag `Closure(idx)`.

## Hors-périmètre
- La **glue** d'émission Rust (`.clone()`, `.collect()`, mutation, closure) → 40200.
- Itérateurs **lazy/infinis** (ne se `collect` pas), **mutation-via-emprunt** (`get_mut` réutilisé) → **non
  reconnus** (D6, résidu dur → `rust:`/`.iri` curé).

## Comportement attendu
```rust
impl RegexBuilder {
    pub fn case_insensitive(&mut self, yes: bool) -> &mut RegexBuilder { … }  // builder
}
impl Captures { pub fn get(&self, i: usize) -> Option<Match> { … } }          // getter (Match emprunté)
impl Regex { pub fn find_iter<'t>(&self, t: &'t str) -> Matches<'t> { … } }    // iterator
```
→
```
fn case_insensitive(inout self, yes: bool) -> unit = "case_insensitive" [builder]
fn get(self, i: i64) -> Option[Match]              = "get" [clone]
fn find_iter(self, t: str) -> list[(i64,i64)]      = "find_iter" [collect]
```
Côté Iron : `b.case_insensitive(True); m = caps.get(0); spans = r.find_iter(text)` — **style Python**.

## Contrat / interface
`bind/idioms.rs` : `pub fn tag_idioms(b: &mut Bindings)` — mute en place les `ExternFn` (ajoute `idioms`,
normalise `ret`/`recv`/`params`). Ordre d'application documenté (builder avant getter : un `&mut Self` n'est
pas un getter). Conservateur : en cas d'ambiguïté, **ne pas taguer** (laisse en `C` → sauté).

## Source maps
N/A au binding. La glue I8 est posée par 40200 (chaque idiome reste rattaché au `Span` de l'appel Iron).

## Critères d'acceptation
- Sur `regex` : builders (`RegexBuilder`), getters (`Captures::get`), iterators (`find_iter`) → tagués (comptés).
- Un retour `&mut Self` n'est **jamais** tagué `Clone` (ordre builder>getter testé).
- Idiome ambigu (retour `&T` mais `recv ByRefMut`) → non tagué, compté en sauté (pas de binding faux).
- Mesure : couverture `regex`/`serde_json` après idiomes ≥ celle annoncée au cadrage (≥ 90 %).

## Décomposition
→ planif `2.3` : 4 détecteurs + normalisation de signature + ordre/anti-ambiguïté + comptage.

## Risques / questions ouvertes
- 🔶 Détection « iterator » sans `impl Iterator` explicite (type nommé `Matches`) : heuristique sur `impl
  Iterator for Matches` dans le rustdoc → fiable si présent, sinon non tagué. Dégrade proprement.
- 🔶 Closure à capture/`FnMut` multi-appels : la lambda Iron suffit au cas courant ; cas exotiques → résidu dur.
