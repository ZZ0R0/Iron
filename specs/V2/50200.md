# [50200] Bindings `.iri` manuels

- Version : V2 · Milestone : M4 · Statut : draft · Dépend de : 50100 · Invariants : I7, I6, I2, I8

## Objectif
Niveau 2 (I7) : déclarer des items Rust externes dans un `.iri`, les **importer** et les appeler
**type-checkés** depuis Iron.

## Périmètre
Format `.iri` déclaratif + `use "x.iri"` + vérification de type des appels + dépendance crate.

## Hors-périmètre
Auto-génération (→ 50300). Génériques dans les bindings (V3).

## Comportement attendu (observable)
- `.iri` : `extern fn sqrt(x: f64) -> f64 = "f64::sqrt"` · `extern type Inst = "std::time::Instant"` ·
  `crate rand = "0.8"`.
- `.irn` : `use "math.iri"` en tête → `sqrt(2.0)` appelable, **type-checké** contre la signature, **loweré**
  vers `f64::sqrt(2.0)`.
- Dépendance : `crate …` d'un `.iri` importé → ajoutée au `[dependencies]` du `Cargo.toml` généré.
- Type opaque → `Type::Extern(name)` côté Iron (boîte noire, valeur I1).

## Contrat / interface
Parser `.iri` → table d'externs (sig + `rust::path` + crates). `use` charge la table → fusionnée dans
`Sigs`/`Structs`/`Extern` de l'inférence. Lowering : appel extern → `rust::path(args)`. Driver : émet
`[dependencies]`.

## Source maps
Erreur de type sur appel extern → span de l'appel Iron (I8, mécanisme existant).

## Critères d'acceptation
Un `.iri` (binding `std` ou crate réelle) importé via `use`, appelé, type-checké → `cargo` vert + exécution ;
la dépendance apparaît dans le `Cargo.toml` généré.
