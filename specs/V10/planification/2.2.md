# [2.2] Unification + résolution des contraintes de trait

- Spec parente : 21900 · Version : V10 · Dépend de : 1.1 · Statut : todo · **Vague 2** (parallèle)

## But
Le **solveur** : unifier les `Eq`, résoudre les **contraintes de trait** (`T: Add`/`Ord`/…) qui modélisent
l'**overloading** (`+` add/concat, `<`/`==` polymorphes). Le point dur de V10 — traité par instances de
trait (miroir des traits Rust), avec **dégradation gracieuse** sur l'ambiguïté.

## Fichiers touchés
`src/infer/engine/solve.rs` (**possédé**, créé vide en 1.1). Lecture seule : `constraint.rs`, `subst.rs`.

## Étapes
1. Unification `Eq(t1,t2)` : var↔type, structurel, **occurs-check** ; met à jour `Subst`.
2. Table d'instances **primitives** : `i64/f64: Add+Sub+Mul+Div+Ord+Eq+Display`, `str: Add(concat)+Ord+Eq+
   Display`, `bool: Eq+Display`… (extensible par 2.3 pour les types bindés).
3. Résolution `Trait(t, B)` : instance trouvée → ok ; `t` encore `Var` → **différer** ; point fixe.
4. Fin de course : contrainte de trait sur var encore libre/ambiguë → `TypeError::Ambiguous` (→ 3.2), **pas**
   de panique.

## Critère de done
`+` sur i64 → addition, sur str → concat (les deux solvent) ; `<`/`==` sur i64/str/struct ; contrainte
insatisfaisable → `TypeError` net ; ambiguïté → erreur « annote » avec span. **Testable avec des contraintes
montées à la main** (sans gen).

## Notes
Parallèle à 2.1/2.3. Garder l'ensemble de traits **petit et béni** — pas de typeclasses générales. Hors
ensemble → filet `rust { }`/annotation (D7).
