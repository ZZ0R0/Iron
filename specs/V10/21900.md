# [21900] Unification + résolution des contraintes de trait (overloading)

- Version : V10 · Milestone : M10 · Statut : draft · Dépend de : 21700, 21800 · Invariants : I2, I6

## Objectif
Le **solveur**. Résoudre le jeu de contraintes (21800) : unifier les `Eq`, et — c'est **le point dur** —
résoudre les **contraintes de trait** (`T: Add`, `T: Ord`, `T: Display`) qui modélisent l'**overloading
ad-hoc** (`+` = add *ou* concat ; `<`/`==` polymorphes). Hindley-Milner pur ne le fait pas ; on s'appuie
sur des **instances de trait** (D3), miroir des traits Rust (I6).

## Périmètre
- **Unification** `Eq(t1, t2)` : algo standard (var↔type, type↔type structurel, occurs-check). Met à jour la
  `Subst`.
- **Résolution de traits** : pour `Trait(t, B)`, chercher une **instance** :
  - primitives : `i64: Add+Ord+Eq+Display`, `f64: …`, `str: Add(concat)+Ord+Eq+Display`, `bool: Eq`…
  - structs/enums Iron : selon dérives/usage (au moins `Eq`/`Display` si demandé) ;
  - **bindings** (22000) : un type externe satisfait B si son `.iri`/Rust le dit.
  - si `t` est encore une `Var` : contrainte **différée** (peut se résoudre après d'autres unifications) ;
    si à la fin elle reste ambiguë → **dégradation gracieuse** : erreur « annote ce type » (pas de crash).
- **Propagation** : ré-appliquer la substitution jusqu'au point fixe.

## Hors-périmètre
- Génération (21800). Méthodes/bindings (22000). Defaulting des littéraux non contraints (22100).

## Comportement attendu
```
a + b   où a: V0, contrainte V0: Add, V0 = V1
  · si V0 unifié à i64  → Add(i64) = addition,     ret i64
  · si V0 unifié à str  → Add(str) = concaténation, ret str
  · si V0 reste libre   → différé ; si jamais résolu → « type ambigu, annote »
```

## Contrat / interface
- `infer/engine/solve.rs` (nouveau) : `solve(constraints, instances) -> Result<Subst, TypeError>`.
- `instances` : table des instances de trait connues (primitives + Iron + bindings). Extensible par 22000.

## Source maps
Un échec d'unification renvoie un `TypeError` portant les **deux spans** en conflit (I8) → 22200.

## Critères d'acceptation
- `+` sur `i64` → addition ; sur `str` → concat ; les deux compilent et donnent le bon Rust (test).
- `<`/`==` résolus sur i64/str/struct dérivant les traits.
- Contrainte de trait insatisfaisable → `TypeError` clair (pas un mismatch rustc obscur).
- Var libre ambiguë en fin de course → message « annote » sur le bon span (dégradation gracieuse).

## Décomposition
→ planif : (1) unification + occurs-check ; (2) table d'instances primitives ; (3) résolution + différé +
point fixe ; (4) ambiguïté → dégradation gracieuse.

## Risques / questions ouvertes
- 🔶 **C'est LE risque de la version.** Garder l'ensemble de traits **petit et béni** (D3) ; ne pas viser un
  système de typeclasses général. Tout ce qui sort de l'ensemble → `rust { }` / annotation (filet D7).
- 🔶 Cohérence des instances (pas deux instances contradictoires) : l'ensemble béni étant fixe, faible risque.
