# [22100] Defaulting + généralisation (let-polymorphism)

- Version : V10 · Milestone : M10 · Statut : draft · Dépend de : 21900 · Invariants : I6

## Objectif
Clore l'inférence (D5, D6) : (1) **defaulting** des variables numériques restées libres → `i64`/`f64` ;
(2) **généralisation** des génériques utilisateur `def f[T]` en **schémas** quantifiés, instanciés
fraîchement à chaque appel. C'est ce qui fait que `pair_of[T](x)` type `x: T` sans l'écrire, et que les
littéraux nus se résolvent comme en Rust.

## Périmètre
- **Defaulting** : après unification au point fixe, toute `Var` avec contrainte `Integral`/`Fractional` non
  résolue → `i64`/`f64`. Appliqué **après** tout le reste (sinon ré-introduit le bug « str dans `+` → i64 »).
  Une `Var` **sans** contrainte exploitable et non défautable → erreur « type ambigu, annote » (22200).
- **Généralisation** : à la frontière d'une `def f[T]`, les `Var` non liées à l'extérieur deviennent le
  paramètre `T` déclaré ; chaque site d'appel **instancie** `T` avec une `Var` fraîche (let-polymorphism).
  La **déclaration** `[T]` reste explicite (D0) ; le **lien** `[T]`↔param/usage est inféré.
- **Récursion mutuelle** : typer par **composantes fortement connexes** (variables de signature partagées
  dans la SCC, généralisées une fois la SCC résolue).

## Hors-périmètre
- Génération/unification (21800/21900). Diagnostics (22200).

## Comportement attendu
```
def pair_of[T](x):     # x: V0 ; généralisation lie V0 au T déclaré ⇒ x: T, retour list[T]
    return [x, x]
pair_of("hi")          # instancie T := str  ⇒ list[str]
print(2 + 3)           # 2,3: Var Integral non contraintes ⇒ defaulting i64
```

## Contrat / interface
- `infer/engine/generalize.rs` (nouveau) : `default_unconstrained(subst)`, `generalize(fn, subst) -> Scheme`,
  `instantiate(scheme) -> Type`. Ordonnancement par SCC du graphe d'appels.

## Critères d'acceptation
- `pair_of[T](x)` (sans `x: T`) compile et donne `fn pair_of<T: Clone>(x: T) -> Vec<T>` (test).
- Littéraux nus défautent `i64`/`f64` comme attendu (pas de `Var` fuité).
- Fonctions mutuellement récursives non annotées typent correctement (test SCC).

## Décomposition
→ planif : (1) defaulting numérique en clôture ; (2) généralisation + instanciation ; (3) ordre SCC pour la
récursion mutuelle.

## Risques / questions ouvertes
- 🔶 Lier une `Var` au `T` **déclaré** plutôt qu'à une `Var` séparée (le bug actuel de `pair_of[T](x)`) : la
  généralisation doit **réutiliser** le `T` de la signature, pas en créer un neuf.
- ⏸️ Inférer la **déclaration** `[T]` elle-même (générique implicite) = ambition HM-global (B), **écartée**
  par D0. Reporté.
