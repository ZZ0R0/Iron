# [22200] Diagnostics de type Iron (mismatch → span) ; rustc filet

- Version : V10 · Milestone : M10 · Statut : draft · Dépend de : 21900, 60800 · Invariants : I2, I8

## Objectif
Iron sait enfin **diagnostiquer un type lui-même** (D8) : un échec d'unification ou une contrainte de trait
insatisfaisable devient un **message Iron sur le bon span** (« attendu `str`, trouvé `i64` »), **avant**
`rustc`. La surcouche rustc (60800) **reste** le second rideau (D7/I2) pour ce que le moteur ne couvre pas.

## Périmètre
- **`TypeError`** (de 21900) → diagnostic : message lisible + **span Iron** primaire (et secondaire pour le
  conflit), via les spans portés par les contraintes (21700).
- **Catégories** : mismatch d'unification · trait non satisfait (`str` pas `Ord` avec X…) · type ambigu
  (var non défautable) · arité d'appel · champ/méthode inconnu.
- **Cohabitation rustc (D7)** : le moteur tourne d'abord ; s'il passe, on transpile et `rustc` reste le filet
  (mémoire/emprunts + trous résiduels remontés par 60800). **Jamais** d'`unsafe` (I2).
- **`ironc check`** : utilise en priorité les diagnostics Iron (plus rapides, plus précis), rustc en complément.

## Hors-périmètre
- Le moteur lui-même (21700–22100). La remontée rustc existe déjà (60800) — on s'y **branche**, on ne la
  réécrit pas.

## Comportement attendu
```
def add(a, b): return a + b
add(1, "deux")
→ ironc: erreur: 2:11: type incompatible — `add` attend un nombre, reçu `str`  (avant même rustc)
```

## Contrat / interface
- `infer/engine/diag.rs` (nouveau) : `TypeError → CompileError` (message FR + span). Réutilise
  `line_col`/le format de `driver::remontee`.
- `infer()` renvoie désormais `Result<TypeMap, CompileError>` (l'inférence peut **échouer proprement**).

## Source maps (I8)
**Cœur de la spec** : chaque diagnostic pointe la **ligne Iron** d'origine, pas le Rust généré. C'est l'I8
appliqué à l'inférence (l'analogue de la remontée rustc, mais natif).

## Critères d'acceptation
- Un jeu de programmes mal typés → message Iron **sur le bon span** (test : ≥ 1 par catégorie).
- Le message Iron précède la remontée rustc (qui reste dispo si le moteur laisse passer).
- 0 `unsafe` (I2) ; aucun faux-positif sur le corpus correct (50) + binding (30).

## Décomposition
→ planif : (1) `TypeError → CompileError` + spans ; (2) catégories de messages ; (3) câblage `infer()`
faillible + `ironc check` ; (4) corpus de tests négatifs.

## Risques / questions ouvertes
- 🔶 Qualité du message sur les contraintes de trait différées (l'origine peut être loin du symptôme) :
  garder le span de la **contrainte source**, pas du point de détection.
